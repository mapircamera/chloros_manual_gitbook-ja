# DAQ 光センサー

> **ハードウェアについてお探しですか？**センサー自体（モデル、取り付け方法、キャップ、ポート、電源、および SCANNER アプリ）については、**[DAQ ユーザーマニュアル](https://mapir.gitbook.io/daq)**に記載されています。 この章では、Chloros からの使用方法について説明します。

MAPIR の **DAQ** 光センサーは、放射測定的に校正されたスペクトルとして周囲の光を測定します。Chloros では、これらは 2 つの役割を果たします：

* **スタンドアロンの分光測定器** — ライブスペクトルチャート、測色データ、および `.daq` による記録は、すべて [「光センサー」タブ](gui.md)、[CLI](cli-quick-start.md)、またはPython SDK から取得できます。
* **反射率計算用の下向き放射照度源** — 処理中に、 Chlorosは、`.daq`の測定値を各キャプチャの露出タイムスタンプに合わせて補間し、測定された下向放射光を用いてカメラの放射輝度を反射率（`--reflectance-source daq`）に変換します。キャリブレーション済みのバンドについては、シーン内パネルは不要です。

## 3つのモデル、1つのデータ形式

| モデル | 転送方式 | 検出方式 |
| --- | --- | --- |
| **DAQ-U** | USB（シリアル） | シリアルポートスキャン |
| **DAQ-M** | Bluetooth Low Energy | 名前によるBLEスキャン |
| **DAQ-E** | イーサネット (IPv4、PoE給電) | mDNS `_daq-e._tcp` (ホスト名 `daq-e-<id>.local`) |

**DAQ-E-S (バージョン 1.3.0 で新規追加)。** 固定式ディフューザーと傾斜センサーを備えたDAQ-Eです。Chlorosでは`DAQ-E-S`として登録されており、キャップ補正を行わない点と、すべての測定値にユニットの傾斜、ロール、ピッチが含まれる点を除き、DAQ-Eと全く同じように動作します。 [DAQ-E-S: 固定ディフューザーおよび傾斜](caps-and-range.md#daq-e-s-fixed-diffuser-and-tilt)を参照してください。

これら3機種はすべて同じ通信プロトコルを採用しており、同一のデータを出力します：

* **340～1010 nmの範囲で5 nm刻みの135点スペクトル**に加え、各フレームごとにCIE XYZ三刺激値が含まれます。
* **W/m²/nm単位の放射測定校正済み分光放射照度** — データがユーザーに届く前に、各ユニットの工場出荷時校正バンドル（およびアクティブなキャップ補正プロファイル）が適用されます。
* 同一の**`.daq`記録フォーマット**（SQLiteファイル）。どのトランスポートでファイルが生成されたかに関わらず、下流処理は同一です。

トランスポートスタック（USBシリアル、BLE、mDNS/zeroconf）はChlorosバックエンド内にバンドルされています。GUIやCLIの`pool-*`コマンドからこれら3つのモデルのいずれと通信する場合でも、別途インストールする必要はありません。

## 校正範囲：報告値 340–1010 nm、校正値 約 374–974 nm

センサーは 340–1010 nm の全グリッドを報告しますが、NIST トレーサブルな放射計ゲインの範囲は、およそ **374–974 nm** です。 Chlorosは、その校正範囲内のスペクトル重みが半分未満であるカメラバンドについては、絶対反射率による分割を拒否します。スキップされたバンドは、スキップ理由 `dls-uncalibrated-band-<nm>` とともに報告されます。

出荷中の LATTICE フィルター SKU の中で、影響を受けるのは **F988** のみです：

F988 の反射率は、現場の反射率パネルを使用して校正されます。このバンドは DAQ 光センサーの校正範囲外にあるため、Chloros は最新のパネルキャプチャデータを適用し、パネル測定の合間もそのデータを保持します。

F988のキャプチャがDAQデータのみを利用して処理される場合、ChlorosはそのバンドのDAQベースの反射率を拒否し、スキップ理由として`dls-uncalibrated-band-988`を返します — F988 では、[反射率パネルワークフロー](../calibration-targets.md) がサポートされている手順です。

## センサー ID

すべてのDAQは、安定したセンサーIDを報告します。その形式はモデルによって異なります：

| モデル | IDの形式 | 例 |
| --- | --- | --- |
| DAQ-U | 5オクテットのハイフン区切り | `CB-7C-A8-2E-5F` |
| DAQ-M | 5オクテットのハイフン区切り | `CB-74-02-30-6B` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

センサーIDは以下の通りです：

* 記録されるすべての`.daq`ファイルに刻印されており、
* Chlorosがそのユニットの工場出荷時キャリブレーションバンドルを取得するために使用するキーであり、
* CLIの`pool-*`コマンドで`--sensor-id`に渡す値、および
* DAQ-E の場合、その mDNS ホスト名（`daq-e-def330.local`）も — `--eth-host` が受け付ける値です。

## 工場出荷時校正とクラウド

すべてのDAQユニットは、NISTにトレーサブルな放射測定チェーンを用いて個別に工場校正されており、Chlorosは各ユニットのセンサーIDに基づいて、そのユニット専用の校正バンドルをロードします。 各ユニットごとの校正レポート（PDF）は、[光センサータブ](gui.md)内のセンサー設定からダウンロードできます。

{% hint style="warning" %}
**DAQ-UおよびDAQ-Mは、校正のためにクラウドへのアクセスが必要です。**どちらのモデルも本体には何も保存されません。工場出荷時の校正データはMAPIRのクラウドに保存されており、センサーIDに基づいて取得され（その後、ローカルにキャッシュされます）。 ChlorosがDAQ-UまたはDAQ-Mから校正済みのW/m²/nmデータを送信するには、インターネット接続が必要です。**DAQ-Eは例外です** — 校正データはデバイス内に保存されています。
{% endhint %}

## 記録データの保存先

| 画面 | デフォルトの `.daq` 保存先 |
| --- | --- |
| GUI — [光センサー] タブ | `<project folder>/light_sensor/` (完了した記録は自動的にプロジェクトに追加されます) |
| CLI — `daq pool-record` | `~/Documents/DAQ Live View/`（バックエンドを実行しているマシン上） （バックエンドが同じコンピュータ上にある場合、相対パス `-o` はコマンドを実行したフォルダを基準に解決されます） |

すべての `.daq` ファイル名には、センサー ID とタイムスタンプが含まれています。
