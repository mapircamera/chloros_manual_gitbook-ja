# DAQ 光センサー

> **ハードウェアについてお探しですか？**センサー自体（モデル、取り付け方法、キャップ、ポート、電源、および SCANNER アプリ）については、**[DAQ ユーザーマニュアル](https://mapir.gitbook.io/daq)**に記載されています。 本章では、Chloros以降のモデルにおける使用方法について解説します。

MAPIRの**DAQ**光センサーは、放射測定学的に校正されたスペクトルとして周囲の光を測定します。Chlorosでは、これらは2つの役割を果たします：

* **独立した分光測定装置** — [「光センサー」タブ](gui.md)から、リアルタイムのスペクトルチャート、測色データ、および `.daq` 記録を取得できます。 [CLI](cli-quick-start.md)、または Python SDK から取得できます。
* **反射率計算用の下向き放射照度源** — 処理中に、Chlorosは`.daq`の測定値を各キャプチャのの各露光タイムスタンプに補間し、測定された下向きの光を用いてカメラの放射輝度を反射率（`--reflectance-source daq`）に変換します。校正済みバンドの場合、シーン内のパネルは不要です。

## 3つのモデル、1つのデータ形式

| モデル | 転送方式 | 検出方式 |
| --- | --- | --- |
| **DAQ-U** | USB (シリアル) | シリアルポートスキャン |
| **DAQ-M** | Bluetooth Low Energy | 名前による BLE スキャン |
| **DAQ-E** | イーサネット（IPv4、PoE給電） | mDNS `_daq-e._tcp`（ホスト名 `daq-e-<id>.local`） |

これら3機種はすべて同じワイヤプロトコルに対応しており、同一のデータを提供します：

* すべてのフレームにおいて、**340～1010 nmの範囲で5 nm刻みの135点のスペクトル**に加え、CIE XYZ三刺激値が含まれます。
* **W/m²/nm単位の放射計的に校正された分光放射照度** — データがユーザーに届く前に、各ユニットの工場出荷時の校正データ（およびアクティブなキャップ補正プロファイル）が適用されます。
* 同一の**`.daq`記録フォーマット**（SQLiteファイル）。どの転送方式でファイルが生成されたかに関わらず、下流処理は同一です。

トランスポートスタック（USBシリアル、BLE、mDNS/zeroconf）は、Chlorosバックエンド内にバンドルされています — GUI や CLI の `pool-*` コマンドからこれら 3 つのモデルのいずれとも通信するために、別途インストールする必要はありません。

***

## 校正範囲：報告値 340–1010 nm、校正値 約 374–974 nm

センサーは 340–1010 nm の全グリッドを報告しますが、NIST トレーサブルな放射計ゲインの範囲はおよそ **374–974 nm** です。 Chlorosは、その校正範囲内のスペクトル重みの半分未満しか含まないカメラバンドについては、絶対反射率の除算を拒否します。スキップされたバンドは、スキップ理由として`dls-uncalibrated-band-<nm>`と共に報告されます。

出荷済みの LATTICE フィルター SKU の中で、影響を受けるのは **F988** のみです：

F988の反射率は、現場の反射率パネルを使用して校正されています。このバンドはDAQ光センサーの校正範囲外にあるため、Chlorosが最新のパネルキャプチャを適用し、パネル測定の合間もその値を保持します。

DAQデータのみが利用可能な状態でF988のキャプチャが処理された場合、ChlorosはそのバンドについてDAQベースの反射率を拒否し、スキップ理由として`dls-uncalibrated-band-988`を返します。F988でサポートされている処理手順は、[反射率パネルのワークフロー](../calibration-targets.md) がF988でサポートされている手順です。

## センサーID

すべてのDAQは安定したセンサーIDを報告します。その形式はモデルによって異なります：

| モデル | ID形式 | 例 |
| --- | --- | --- |
| DAQ-U | 5オクテット、ハイフン区切り | `CB-7C-A8-2E-5F` |
| DAQ-M | 5オクテットのハイフン区切り | `CB-74-02-30-6B` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

センサーIDは以下の通りです：

* 記録されるすべての `.daq` ファイルに刻印されており、
* Chloros がそのユニットの工場出荷時キャリブレーションバンドルを取得するために使用するキーであり、
* CLI および `pool-*` コマンドにおいて `--sensor-id` に渡す値、および
* DAQ-E については、その mDNS ホスト名（`daq-e-def330.local`）も記録されます。これは、`--eth-host` が受け入れる値です。

***

## 工場出荷時校正とクラウド

すべてのDAQユニットは、NISTにトレーサブルな放射測定チェーンを用いて個別に工場校正されており、Chlorosは各ユニットのセンサーIDに基づいて紐付けられた校正バンドルをロードします。 ユニットごとの校正レポート（PDF）は、[光センサータブ](gui.md)内のセンサー設定からダウンロードできます。

{% hint style="warning" %}
**DAQ-U および DAQ-M は、校正のためにクラウドへのアクセスが必要です。**どちらのモデルも本体には何も保存されません。工場出荷時の校正バンドルは MAPIR のクラウドに保存されており、センサー ID によって取得され（その後、ローカルにキャッシュされます）。 ChlorosがDAQ-UまたはDAQ-Mから校正済みのW/m²/nmデータを送信するには、インターネット接続が必要です。**DAQ-Eは例外です** — このモデルは校正データをデバイス内に保持しています。

## 記録データの保存先

| 表面 | `.daq`のデフォルト保存先 |
| --- | --- |
| GUI — [光センサー] タブ | `<project folder>/light_sensor/` (完了した記録はプロジェクトに自動的に追加されます) |
| CLI — `daq pool-record` | バックエンドを実行しているマシン上の `~/Documents/DAQ Live View/` |

すべての `.daq` ファイル名には、センサー ID とタイムスタンプが含まれています。
