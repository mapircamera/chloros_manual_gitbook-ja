# キャップのプロファイルと校正範囲

> キャップ自体（どのセンサーにどのキャップが付属するか、取り付け方法、および光学特性）については、**[DAQユーザーマニュアル](https://mapir.gitbook.io/daq)**に記載されています。このページでは、Chloros
に対して装着されたキャップを*宣言*する方法について説明します。この宣言を行うことで、補正が正しく行われるようになります。

すべてのDAQ光センサーの工場出荷時の放射測定校正は、*素の*センサーの状態を記述したものです。ディフューザーの上に装着された物理的なキャップは、センサーが収集する光の性質を変えるため、Chloros
は校正バンドルに加えて、工場で測定された**キャップ補正プロファイル**を適用します。 正しいキャップを指定することは、校正済みデータを取得するための重要な手順です。このページでは、モデルごとのキャップの種類、指定方法、およびセンサーの実際の校正済みスペクトル範囲について解説します。

## モデル別のキャップの有無

| キャッププロファイル (`cap_id`) | 物理的なキャップ | DAQ-U | DAQ-M | DAQ-E |
| --- | --- | --- | --- | --- |
| `sunshine_cosine` | サンシャイン・コサイン補正キャップ（**全モデルでデフォルト**） | あり | あり | あり |
| `fov_15` / `fov_45` / `fov_90` | 視野制限コーン（15° / 45° / 90°） | あり | — | あり |
| `fov_30` / `fov_60` | 視野制限コーン（30° / 60°） | あり | — | — |
| `none` | キャップ未装着 | — | — | はい |

モデル固有の注意事項：

* **DAQ-Mには1つのキャッププロファイル（`sunshine_cosine`）があります。** 「ベア＋サンシャインキャップ」が製品定義であり、ベア状態のDAQ-Mには幾何学的プロファイルは不要です。
* **ベア状態のDAQ-Uは完全な「ベア」です** — 幾何学的プロファイルは一切不要であるため、このモデル用の`none`プロファイルは存在しません。
* **DAQ-Eにおける`none`は、単なる「何もしない」設定ではありません。** DAQ-Eの窪んだガラス被覆ディフューザーには独自の幾何学的補正があるため、このモデルでは「キャップなし」自体が測定プロファイルとなります。
* **キャップを装着していない DAQ-E では、いかなる高度の直射日光も測定できません** — サンシャインキャップの装着が現場での標準的な設定です。キャップを装着していない DAQ-E を使用した屋外作業は計画しないでください。

GUIのセンサーごとの設定（[Light Sensors]タブの歯車アイコン）にある**Cap**ドロップダウンには、DAQ-UおよびDAQ-Mでも「None (bare sensor)」という選択肢があります。これら2つのモデルにおいて、「bare」とは、前述の注記通り、キャップ補正が適用されないことを単に意味します。 キャップが物理的に取り外されている場合にのみ、これを選択してください。

## キャップの指定 — およびその重要性

**指定された `cap_id` は、センサーに物理的に装着されているキャップと一致している必要があります。** センサーもソフトウェアも、装着されているキャップを検出することはできません。この指定は、以下の2つの要素に影響を与えます：

1. すべてのスペクトルに適用される**リアルタイム補正**。
2. **すべての `.daq` 記録に書き込まれるキャップスタンプ**。これは、下流の反射率処理で信頼される情報です。

Sunshineキャップは**設計上、約12倍**の減衰効果を持つため、誤ったキャップを宣言して記録すると、スペクトルのスケールがほぼその倍率分だけずれてしまいます。キャップの変更は直ちに宣言してください。

### キャップの設定

GUI：[Light Sensors]タブ → センサー行の歯車アイコン → **Cap**ドロップダウン。 すべてのモデルのデフォルトは `sunshine_cosine` です。これは仮定値であり（DAQ-U、DAQ-M、DAQ-E にはキャップが付属しておらず、キャップを選択するまでは記録データには「キャップが仮定された」と表示されます）、選択内容はプロジェクトに保持されます。



CLI<!-- SCREENSHOT-NEEDED: DAQ tab per-sensor settings modal (gear icon) scrolled to the Cap dropdown, open to show the per-model choices with "Sunshine (cosine corrector)" selected. Use a connected DAQ-E so the Hostname/Firmware/PTP rows are also visible above it. -->
（バックエンドが実行中である必要があります）：

```bash
# Declare at connect time
chloros-cli daq pool-connect --eth-host daq-e-def330.local --cap-id sunshine_cosine

# Swap at runtime (after physically changing the cap)
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id fov_45
```

CLI
は、構文上、完全な`cap_id`リスト（`{none, fov_15, fov_30, fov_45, fov_60, fov_90, sunshine_cosine}`など）を受け付けます。 各プロファイルは接続時にセンサーのモデルに対して検証されるため、利用できないキャップ ID（例：DAQ-U での E 専用 ID）は、誤った補正を行うことなく明確なエラーとして失敗します。何も指定されない場合のバックエンドのデフォルトは `sunshine_cosine` です。

Python
SDK
：接続時に `connect_daq_sensor(cap_id="sunshine_cosine")` を使用してキャップに名前を付けるか、実行時に `DAQSensorSession.set_cap("fov_45")` を使用してキャップを切り替えてください。[SDK
リファレンス](../reference/sdk-reference.md#daq-sensor-sessions) を参照してください。

上級者向け：プロファイルはChloros
のインストール内に`daq/cap_profiles/<u|m|e>/<cap_id>.json`として同梱されており、ユーザーごとに`~/.chloros/daq_cap_profiles/<u|m|e>/<cap_id>.json`で上書き可能です。

上限とは別に、再校正されたことのないセンサーには、ユーザーによる操作を必要とせずに、フリートデータに基づく微小なダークオフセットの補正が自動的に適用されます。

## DAQ-E-S：固定ディフューザーおよびチルト

**DAQ-E-S**は、Chloros
にとって重要な2つの違いがあるDAQ-Eです。それ以外の機能（検出、接続、PTP、記録、デバイス設定）は、DAQ-Eとまったく同じように動作します。

* **そのディフューザーは固定式であるため、キャップ補正は必要ありません。** このディフューザーは、工場出荷時の校正測定時にユニットに装着されていたため、その校正値はすでに真のダウンウェル放射照度を示しています。Chloros
は、どのような要求があってもこのユニットにキャッププロファイルを適用しません。このユニット用に名付けられたキャップはメッセージを表示して無視され、記録データにはキャップがモデル由来であると表示され、想定キャップに関する警告もこのユニットに対しては決して発動しません。 [プロジェクト設定] → [DAQ 光センサー] の行にはキャップが表示されず、プロジェクト全体のキャップ上書き設定もこのセンサーには適用されません。手動でデータにキャップを適用しないでください。そうすると、上乗せされるサンシャイン補正値が約 11 倍高くなってしまいます。
* **3 軸加速度計を搭載しています。** ディフューザーのコサイン応答は、水平な状態でのみ有効であるため、センサーが傾いていると、他の兆候は現れず、誤った放射照度が報告されます。したがって、各DAQ-E-Sの測定値には、その傾き、ロール、ピッチが含まれており、このセンサーから記録された`.daq`は、すべてのスペクトルの横にこれらの情報を保存します (`imu_tilt_deg`、`imu_roll_deg`、`imu_pitch_deg`、…)、これにより、雲による影響とマウントの傾きによる影響を区別できます。

各姿勢フィールドおよび姿勢ストリームの障害の報告方法については、[CLI
リファレンスのDAQ-E-S](../reference/cli-reference.md#daq-e-s--fixed-diffuser-and-tilt-sensor)を参照してください。

## サンシャインキャップの性能（屋外構成）

手順策定の根拠となる数値：

| 特性 | 値 |
| --- | --- |
| 視野 | 180° 半球状 |
| コサイン応答誤差 | 入射角 60° まで ≤ ±4 %；70° まで ≤ ±4.5 % |
| 低日射角の限界 | 太陽高度角約15°未満での使用は推奨されません |
| 減衰率 | 約12倍（設計値） |
| キャップ再取り付け時の再現性 | ≈ 1.5 % |
| 定量的放射照度 | **15秒以上**の測定値の平均（機器の特性であり、不具合ではありません） |

定量的放射照度の数値（反射率の参照値を含む）については、単一のフレームではなく、少なくとも15秒間の測定値の平均値を使用してください。

## 校正済み分光範囲

| 特性 | 値 |
| --- | --- |
| 分光サンプリング | 340–1010 nm（5 nm 刻み、135 ポイント） |
| 放射測定校正範囲 | **~374–974 nm**（ソフトウェアで強制適用） |

センサーは 340–1010 nm の全グリッドを報告しますが、NIST トレーサブルな放射測定ゲインの範囲は ~374–974 nm です。 Chloros
は、その範囲内にスペクトル重みの半分未満しか含まれないカメラバンドについては**絶対反射率の分割を拒否**し、未校正のデータを生成する代わりに、スキップ理由`dls-uncalibrated-band-<nm>`を報告します。 現在出荷中のカメラSKUのうち、この範囲外となるのはF988フィルターのみです。このモデルでは代わりに反射率パネルワークフローが使用されます — [反射率ワークフロー](reflectance.md)を参照してください。

センサーモデル、トランスポート、およびセンサー ID については、[DAQ の概要](README.md) を参照してください。処理中にキャップスタンプがどのように消費されるかについては、[記録と .daq フォーマット](recording.md) を参照してください。
