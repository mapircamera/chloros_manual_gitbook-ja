# キャップのプロファイルと校正範囲

> キャップ自体（どのセンサーにどのキャップが同梱されているか、取り付け方法、光学特性など）については、**[DAQユーザーマニュアル](https://mapir.gitbook.io/daq)**に記載されています。 このページでは、Chlorosに対して装着されたキャップを*宣言*する方法について説明します。この宣言を行うことで、補正が正しく行われるようになります。

すべてのDAQ光センサーの工場出荷時の放射測定較正は、*裸*のセンサーについて記述されています。ディフューザーの上に装着された物理的なキャップは、センサーが収集する光の変化をもたらすため、Chlorosは、較正バンドルに加えて、工場で測定された**キャップ補正プロファイル**を適用します。 正しいキャップを指定することは、校正済みデータを取得するための重要な手順です。このページでは、モデルごとのキャップの種類、指定方法、およびセンサーの実際の校正済みスペクトル範囲について解説します。

## モデルごとのキャップの有無

| キャッププロファイル (`cap_id`) | 物理的なキャップ | DAQ-U | DAQ-M | DAQ-E |
| --- | --- | --- | --- | --- |
| `sunshine_cosine` | サンシャイン・コサイン補正キャップ（**全モデルでデフォルト**） | あり | あり | あり |
| `fov_15` / `fov_45` / `fov_90` | 視野制限コーン（15° / 45° / 90°） | あり | — | あり |
| `fov_30` / `fov_60` | 視野制限コーン（30° / 60°） | あり | — | — |
| `none` | キャップ未装着 | — | — | あり |

モデル固有の注意事項：

* **DAQ-M には 1 種類のキャッププロファイル：`sunshine_cosine` があります。** 「ベア＋サンシャイン・キャップ」がその製品定義であり、ベア状態のDAQ-Mには幾何学的プロファイルは必要ありません。
* **ベア状態のDAQ-Uは完全な「ベア」です** — 幾何学的プロファイルは一切必要としないため、このモデル用の`none`プロファイルは存在しません。
* **DAQ-Eにおける`none`は、単なる「何もしない」設定ではありません。** DAQ-Eの窪んだガラス被覆ディフューザーには独自の幾何学的補正があるため、このモデルでは「キャップなし」自体が測定プロファイルとなります。
* **キャップを装着していないDAQ-Eでは、いかなる仰角でも直射日光を測定することはできません** — サンシャインキャップの装着が現場での標準的な設定です。キャップを装着していないDAQ-Eを使用した屋外作業は計画しないでください。

GUIのセンサーごとの設定（[Light Sensors]タブ内の歯車アイコン）にある**Cap**ドロップダウンメニューには、DAQ-UおよびDAQ-Mでも「None (bare sensor)」という選択肢があります。これら2つのモデルにおいて、「bare」とは、前述の注記通り、キャップ補正が適用されないことを単に意味します。 キャップが物理的に取り外されている場合にのみ、これを選択してください。

## キャップの指定 — およびその重要性

**指定された `cap_id` は、センサーに物理的に装着されているキャップと一致している必要があります。** センサーもソフトウェアも、装着されているキャップを検出することはできません。この指定は、以下の2つの要素に影響を与えます：

1. すべてのスペクトルに適用される**リアルタイム補正**。
2. **すべての `.daq` 記録に書き込まれるキャップスタンプ**。これは、下流の反射率処理で信頼される情報です。

Sunshineキャップは**設計上、約12倍**の減衰効果を持つため、誤ったキャップを宣言して記録すると、スペクトルのスケールがほぼその倍率分だけずれてしまいます。キャップの変更は直ちに宣言してください。

### キャップの設定

GUI：[Light Sensors]タブ → センサー行の歯車アイコン → **Cap**ドロップダウン。 すべてのモデルのデフォルトは `sunshine_cosine` です（すべての DAQ センサーにはコサイン補正機能が標準搭載されています）。この設定はプロジェクトごとに保持されます。

<!-- SCREENSHOT-NEEDED: DAQ tab per-sensor settings modal (gear icon) scrolled to the Cap dropdown, open to show the per-model choices with "Sunshine (cosine corrector)" selected. Use a connected DAQ-E so the Hostname/Firmware/PTP rows are also visible above it. -->

CLI（バックエンドが実行中である必要があります）：

```bash
# Declare at connect time
chloros-cli daq pool-connect --eth-host daq-e-def330.local --cap-id sunshine_cosine

# Swap at runtime (after physically changing the cap)
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id fov_45
```

CLIは、構文上、`cap_id`のリスト全体を受け入れます（`{none, fov_15, fov_30, fov_45, fov_60, fov_90, sunshine_cosine}`など）。 各プロファイルは接続時にセンサーのモデルに対して検証されるため、利用できないキャップID（例えば、DAQ-U上のE専用IDなど）は、誤った補正を行うのではなく、明確なエラーとして失敗します。何も渡されない場合のバックエンドのデフォルトは `sunshine_cosine` です。

Python SDK 注： `cap_id` は **SDK** のノブではありません。`connect_daq_sensor()` および `DAQSensorSession` はキャップパラメータを公開していません。 上記の CLI コマンドまたは GUI のドロップダウンからキャップを選択してください。[SDK リファレンス](../reference/sdk-reference.md) を参照してください。

詳細：プロファイルは Chloros インストール内に `daq/cap_profiles/<u|m|e>/<cap_id>.json` として同梱されており、`~/.chloros/daq_cap_profiles/<u|m|e>/<cap_id>.json` でユーザーごとに上書き可能です。

上限とは別に、再校正されたことのないセンサーには、ユーザーによる操作を必要とせずに、フリートデータに基づいたわずかなダークオフセットの微調整が自動的に適用されます。

## サンシャインキャップの性能（屋外設定）

手順策定の根拠となる数値：

| 特性 | 値 |
| --- | --- |
| 視野 | 180° 半球状 |
| コサイン応答誤差 | 入射角 60° まで：±4 % 以下；70° まで：±4.5 % 以下 |
| 低日射角の制限 | 太陽高度角約15°未満での使用は推奨されません |
| 減衰 | 約12倍（設計上） |
| キャップ再装着時の再現性 | ≈ 1.5 % |
| 定量的放射照度 | **15秒以上**の測定値の平均（機器の特性であり、不具合ではありません） |

定量的放射照度の数値（反射率の参照値を含む）については、単一のフレームではなく、少なくとも15秒間の測定値の平均値を使用してください。

## 校正済み分光範囲

| 特性 | 値 |
| --- | --- |
| 分光サンプリング | 340–1010 nm（5 nm刻み、135点） |
| 放射測定校正範囲 | **~374–974 nm**（ソフトウェアで強制適用） |

センサーは 340–1010 nm の全グリッドを報告しますが、NIST トレーサブルな放射測定ゲインの範囲は ~374–974 nm です。 Chlorosは、その範囲内にスペクトル重みの半分未満しか含まれないカメラバンドに対しては、**絶対反射率による除算を拒否**し、未校正の成果物を生成する代わりに、スキップ理由として`dls-uncalibrated-band-<nm>`を報告します。 出荷中のカメラSKUのうち、この範囲外となるのはF988フィルターのみです。このフィルターでは、代わりに反射率パネルワークフローが使用されます — [反射率ワークフロー](reflectance.md)を参照してください。

センサーモデル、トランスポート、およびセンサー ID については、[DAQ の概要](README.md) を参照してください。処理中にキャップスタンプがどのように消費されるかについては、[記録と .daq フォーマット](recording.md) を参照してください。
