# 画像グリッド

プロジェクトに画像をインポートすると、メインエリアにグリッド形式で表示されます。このグリッドでは、**各画像のどのバージョンを表示するか**を選択できます。グリッド上部のボタンをクリックすると、すべてのサムネイルを一度に、ソースファイルと各処理済み画像の間で切り替えることができます。

## サムネイルのサイズ

右上のズームスライダーを使用して、画像サムネイルのサイズを調整します。スライダーの範囲は**64 px から 1200 px**です。

* **Ctrl キー + マウスホイール** でもサムネイルの拡大・縮小が可能です。
* **Ctrl + `+`**/**Ctrl + `=`**および**Ctrl + `−`** を押すたびに、サイズが 4 px ずつ変更されます。 キーボード操作による変更範囲は、最小で 64 ピクセル、最大で現在のウィンドウに 1 行につき 2 枚のサムネイルがぴったり収まるサイズまでです。
* 決定したサイズはプロジェクトと一緒に保存されます（`UI → Grid thumbnail size` から `project.json`、デフォルトは `160`）。そのため、プロジェクトを再度開くとそのサイズが復元されます。

<figure><img src="../.gitbook/assets/chloros_grid_zoom.gif" alt=""><figcaption></figcaption></figure>サムネイルの *解像度* は、サムネイルの *サイズ* とは別の設定です。[プロジェクト設定](../project-settings/project-settings.md) の **表示 → 画像サムネイルの解像度** を参照してください（デフォルトは長辺 512 px）。 「サイズ」はタイルが描画される大きさであり、「解像度」はそれを埋めるために読み込まれる詳細度の程度を指します。***

## グリッドツールバー

グリッド上部のボタン列には、左から右へ最大3つのグループがあります：

1. **トリガーごと / カメラごと** — グループ化モード。 LATTICEキャプチャを含むプロジェクトでのみ表示されます。
2. **カメラフィルターボタン** — LATTICEカメラごとに1つずつ。カメラ単位モードでのみ表示されます。
3. **エクスポート／表示モードボタン** — 各サムネイルにどの製品を表示するかを指定します。

ウィンドウの幅が狭すぎてすべてを表示できない場合、グループは右から左へと折りたたまれ、ホバーするとドロップダウンメニューが表示されます。最初にエクスポート／表示ボタンが折りたたまれ、次にカメラボタンが折りたたまれます。折りたたまれたグループには、現在アクティブな選択肢がラベルとして表示された単一のボタンが残り、そのボタンにカーソルを合わせると、ボタン一式が下にスライドして表示されます。 **「Per Trigger」および「Per Camera」は決して折りたたまれません。

## エクスポート/表示モードボタン

これらのボタンは、グリッド上のサムネイルを表示する画像タイプを切り替えます。**ボタンは、その名前が示す製品が存在するやいなや表示されます** — ソースファイルの場合、これは処理後ではなく、インポート直後を意味します。 Chlorosは処理実行中にプロジェクトの製品を再スキャンするため、各製品がディスクに書き込まれ始めるにつれて、処理中にボタンが表示されます。

### 基本ボタン

一番左のエクスポートボタンには、**実際にインポートした内容**が表示されます：

| インポートした内容 | ボタンのラベル |
| --- | --- |
| Survey3 RAW+JPG | `JPG` |
| RAWフレームの横にプレビューが表示されるLATTICEキャプチャ | `PNG` または `TIFF`（プレビューが表示されている方） |
| ベースファイルが**RAWフレーム**であるLATTICEのキャプチャ | *ボタンなし* — `RAW (Original)`にはすでにそのファイルが表示されている |

混合プロジェクトでは、ラベルは画像の数が最も多い拡張子に従います。

### 製品ボタン

| ボタン | 表示内容 | 表示されるタイミング |
| --- | --- | --- |
| **ターゲット** | キャリブレーションターゲットが検出された画像 | ターゲットが検出された実行後 |
| **反射率** | キャリブレーション済みの反射率画像 | Survey3 プロジェクトのみ — LATTICE プロジェクトでは代わりに `RAW (Reflectance)` を使用するため、グリッドに 2 つの反射率ボタンが表示されることはありません |
| **ホワイトバランス調整済み** | ホワイトバランス調整済みの画像（RGBカメラ） | 処理後 |
| **ヴィネット補正済み** | キャリブレーションされていないヴィネット補正済みフォールバック | 反射率キャリブレーションを適用できず、かつ *ヴィネット補正* がオンだった実行後 |
| **センサー応答** | キャリブレーションされていないセンサー応答のフォールバック | 上記と同様だが、*ヴィネット補正*がオフの場合 |
| **`RAW (<INDEX> Index)`** | 計算されたインデックスごとに1つのボタン | インデックスが設定された実行後 |
| **`<INDEX> LUT`** | カラーマッピングされたインデックスごとに1つのボタン | LUTを設定して実行した後 |
| **`<Index> <Index\|LUT> <NNN>`** | [インデックス/LUTサンドボックス](index-lut-sandbox.md)のエクスポート実行ごとに1つのボタン | サンドボックスのエクスポートが完了した直後 |

### LATTICE レベルボタン

LATTICE キャプチャを含むプロジェクトには、製品名ではなくレベル名がラベルとして付けられた以下のボタンが追加されます：

| ボタン | レベル |
| --- | --- |
| **RAW (オリジナル)** | インポートされたソースの RAW フレーム |
| **RAW (放射輝度)** | Float32 スペクトル放射輝度、W/m²/sr/nm |
| **RAW (反射率)** | uint16 反射率、32768 = ρ 1.0 |

`RAW (Original)`はインポート直後から利用可能です。処理は不要です。LATTICEのインポートにベースボタンが全くない場合（各キャプチャのベースファイルはRAWフレームそのものです）、グリッドは利用可能な最初のレベルボタンに自動的に移動し、ツールバーのハイライトが表示内容と一致するようにします。

2つのレベルのChlorosエクスポートには、**独自のグリッドボタンは存在しません**：

* **デベイヤー処理済み** — `RAW (Original)`ビューはすでにデベイヤー処理済みの状態でレンダリングされるため、視覚的に同一の画像に2つ目のボタンを追加しても無駄になります。 `RAW (Debayered)` 出力データは引き続きディスクに書き込まれ、フルスクリーンレイヤーのドロップダウンから選択可能です。
* **プレビュー** — RGB カメラでは、プレビューは `White Balanced` レイヤーとして登録されており、このレイヤーにはボタンがあります。 マルチスペクトルカメラでは、`RAW (Preview)` として登録されており、全画面レイヤーのドロップダウンからアクセス可能です。

{% hint style="info" %}
これらのレベルボタンは、実際に LATTICE フレームを含むプロジェクトでのみ表示されます。 Survey3 プロジェクトでは、一部の内部レイヤー名が重複して登録されていますが、それらのボタンは除外されるため、Survey3 グリッドでは、おなじみの `JPG / Targets / Reflectance` セットが維持されます。
{% endhint %}

グリッドのサムネイルをクリックすると、**そのグリッドが表示しているのと同じ製品**のフルスクリーン [画像ビューア](opening-an-image-full-screen.md) が開きます — グリッドが `Targets` に設定されている場合、サムネイルをクリックするとエクスポートされたターゲット画像が開きます。

## LATTICE プロジェクトのグループ化：トリガー単位 vs カメラ単位

アレイ撮影では、異なるカメラモジュールから同じ瞬間の画像が複数生成されます。グループ化によって、グリッド上でそれらをどのように配置するかが決まります。 どちらのモードでも、全幅の折りたたみ可能なヘッダーバーが表示されます。**すべてのグループは展開された状態で開始**され、Chlorosはユーザーが閉じたグループの状態を記憶します。折りたたみ状態はモードごとに個別に追跡されるため、「カメラごと」モードでグループを閉じても、「トリガーごと」モードのグループは閉じられません。

### カメラごと（デフォルト）

カメラモジュールごとに1つのグループが作成されます。ヘッダーには、カメラのモデルとシリアル番号（`LATT-M3M — <serial>`）、および写真枚数が表示されます。グループ内のタイルは、撮影イベントの時刻順に並べられます。

このモードでは、ツールバーに **カメラごとに1つのカメラフィルターボタン**（ラベル：`MODEL (SERIAL)`）が表示されます。すべてのカメラが初期状態で選択されています。ボタンをクリックすると、そのカメラの選択が解除され、グリッドからそのグループが削除されます。これは、フライト全体にわたる1つのバンドを迅速に確認するための方法です。

### トリガーごと

キャプチャイベントごとに1つのグループが作成されます。これは、同じトリガーで全モジュールが撮影したフレームのセットです。ヘッダーには、キャプチャ時刻、撮影に参加したカメラの数、およびグループ内のカメラモデルごとのバッジが表示されます。 グループ内のタイルはカメラのシリアル番号順に並べられるため、同じバンドはどのトリガーでも同じ列に配置されます。

混合プロジェクト内の非LATTICE画像はグループ化されず、グループの後に通常のタイルとして表示されます。

## グリッドのサムネイルはGSDブロックサイズに従います

[画像]タブのサイドバーで**GSD (px)**のブロックサイズを設定している場合、グリッドサムネイルもフルスクリーン表示だけでなく、その同じ地上解像度で提供されます。 ブロックサイズが 8 の場合、画像が表示されるアプリ内のあらゆる場所で、表示される各ピクセルは、8 × 8 のソースピクセルブロックの平均値となります。

タイルの幅はそもそも数百ピクセル程度しかないため、粗いブロックサイズでも、フルスクリーン表示で目立つようになるよりもずっと前に、グリッド上では目立った違いがなくなるようになります。たとえば、160ピクセルのタイルに描画される4000ピクセルのフレームの場合、表示される1ピクセルあたり約25個のソースピクセルになります。 コントロール自体については、[画像を全画面で開く](opening-an-image-full-screen.md#gsd-block-size)を参照してください。
