# マップマーカー

「マップ」タブでは、GPS座標に基づいて画像をインタラクティブな2Dマップ上にプロットします。これにより、撮影セッションの地理的な概要を把握でき、インポート直後に処理したくない画像を削除するための最も手っ取り早い方法となります。

<figure><img src="../.gitbook/assets/chloros_map_markers.gif" alt=""><figcaption></figcaption></figure>

## 「マップ」タブの表示方法

1. Chlorosでプロジェクトを開くか、新規作成します
2. GPSメタデータを含む画像をインポートします
3. 左サイドバーの**「マップ」** <img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> タブをクリックします
4. マップ上に、各画像のGPS位置にマーカーが表示されます

{% hint style="info" %}
**GPSが必要**：EXIFメタデータにGPS座標が含まれている画像のみが地図上に表示されます。座標のない画像もプロジェクトには残っており、通常通り処理されますが、マーカーは表示されません。
{% endhint %}

***

## 「マップ」タブからの画像の調整**マップ**<img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> タブには、[**ファイルブラウザ**](../processing-images-gui/adding-files-to-a-project.md) <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> タブと同様に、ファイルの追加 <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> および削除 <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line"> ボタンがあります。ここには、地理的な列を含む、同じプロジェクトファイル一覧が表示されます：

| 列        | 内容                                                           |
| ------------- | ------------------------------------------------------------------ |
| **名前**      | カメラから読み込まれたそのままのファイル名                             |
| **緯度**      | 10進度の度単位、小数点以下6桁                                |
| **経度**      | 10進度の度単位、小数点以下6桁                                |
| **高度**      | メートル単位、小数点以下1桁 — 画像に高度情報が含まれていない場合は `-` |

{% hint style="info" %}
列見出しをクリックするとその列で並べ替えられます。もう一度クリックすると順序が逆になります。
{% endhint %}

{% hint style="warning" %}
**高度は地上からの高さではなく、海抜の高さです。** この値は、画像のEXIF `GPSAltitude`タグから取得されたもので、平均海面を基準としています。 これは地形からの飛行高度ではなく、Chlorosはこの値から地上サンプル距離を算出することはありません。海抜300 mの野原の上空で、地上高（AGL）100 mを飛行するドローンは、ここでは約400 mとして記録されます。 この列は、AGLの測定値としてではなく、外れ値を見つけたり、飛行高度に一貫性があるかを確認するために使用してください。
{% endhint %}

## 画像マーカー

GPSデータを含む各画像には、その座標にマーカーが表示されます。

### マーカーの表示

* マーカーは、各撮影時に記録された正確な座標に配置されます
* マーカーが密集していると、ズームアウトした際に視覚的に重なって見える場合があります。ズームインして区別してください
* 選択され、ハイライト表示されたマーカーは、他のマーカーよりも上に表示されます

### ホバープレビュー

* マーカーに**カーソルを合わせ**ると、その画像のサムネイルとファイル名がポップアップ表示されます
* マーカーを**クリック**すると、その画像が選択され、ポップアップが**固定**されます。他の場所をクリックするまでポップアップは表示されたままになります。ポップアップが固定されている間、他のマーカーにカーソルを合わせてもポップアップが消えることはありません
* これは、地図画面を離れることなく、大規模なセッションの中から特定の1枚の画像を素早く見つけるための方法です

<figure><img src="../.gitbook/assets/image (36).png" alt=""><figcaption><p>[マップ] タブには、プロジェクト内のジオタグ付き画像がすべてプロットされます</p></figcaption></figure>### スーパーズーム

{% hint style="success" %}
**スーパーズーム**：タイルプロバイダーが提供する最大ズームレベルに達しても、さらにズームインすると表示が停止することなくタイルが拡大されるため、互いにほぼ重なっているマーカーを区別することができます。
{% endhint %}

* スーパーズームは、その場所についてプロバイダーが提供する最大ズーム率に**到達**し、タイルの読み込みが完了した場合にのみ有効になります。それより低いズーム率では、ズーム動作は通常通りです
* 範囲は、プロバイダーが提供する最大ズーム率を基準として**1×～32×**となります
* 隅にあるインジケーターには現在のスーパーズーム倍率がパーセンテージで表示され、その横にある**×**ボタンをクリックすると、ワンクリックで通常のズームに戻ります
* ズームアウト時は常に地図本体へ切り替わるため、スーパーズーム状態で閉じ込められることはありません
* スーパーズーム中にズームやパン操作を行うと、その結果生じたオフセットがマップに反映されるため、移動先の中心から外れた領域も空白になることなく、引き続きタイルの読み込みが行われます
* マーカーはラスタライズされずベクター要素として描画されるため、どのスーパーズームレベルでも鮮明な状態を保ちます

## マップタイルプロバイダー

{% hint style="success" %}
**自動選択**: Chlorosは、画像が配置されている場所に対して最適なズームレベルを提供するタイルサービスを選択します。いつでも手動で切り替えることができます。
{% endhint %}

| プロバイダー        | 備考                                                                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Google Maps** | 世界的に広範囲をカバー。4種類のタイルタイプすべてに対応                                                                                                            |
| **Esri ArcGIS**| 特定の地域では、より高解像度の航空写真を提供していることが多い。Esriでは**Terrain**タイルタイプは提供されておらず、Esriが選択されている間は当該ボタンが無効になる |***

## 地図タイルの種類

ボタン（左から右）を使用して、地図レイヤーの種類を選択してください：

![](&lt;../.gitbook/assets/image (14).png&gt;)

| 種類                 | 表示内容                                                                |
| -------------------- | -------------------------------------------------------------------- |
| **地形**          | 地図の詳細（道路、ラベル）を含む標高陰影図。Googleのみ       |
| **地図**              | 標準的な道路地図タイル — 帯域幅を最も消費しないオプション              |
| **衛星**        | 詳細な衛星画像、ラベルなし — 帯域幅を最も多く消費するオプション |
| **ハイブリッド** (デフォルト) | 衛星画像の上に道路とラベルが描画されたもの                |

「地図」タブは**ハイブリッド**で開きます。選択内容は、プロバイダが対応している場合、プロバイダの切り替えにも反映されます。***

## 地図の操作

* **ズーム**：マウスのスクロールホイール、または地図上のズームボタン
* **パン**：クリックしてドラッグ
* **全画面表示**：全画面表示コントロールで地図をウィンドウ全体に拡大***

## ユースケース

### 飛行経路の確認

* ドローン撮影セッションのカバー範囲を一目で確認
* 撮影を逃した箇所を特定
* 飛行が計画された経路に沿っていたかを確認

### 地上測量データの確認

* 地上からの撮影画像の分布状況を確認
* 測量エリアに対するキャリブレーションターゲットのフレーム位置を特定
* 追加撮影が必要な箇所を判断

### 品質管理

* 予期しない場所で撮影された画像を見つけ、処理前に削除する
* 高度順に並べ替えて、誤った高度で撮影されたフレームや、GPS測位が不正確だったフレームを特定する
* 画像の位置情報を現場ノートと照合する

## トラブルシューティング

### マーカーが表示されない

**考えられる原因**

* 画像にGPSメタデータが含まれていない
* 撮影時にカメラのGPSが無効になっていた
* インポート前に他のソフトウェアによってEXIFデータが削除された

**対処法**：カメラでGPSが有効になっていることを確認し、元のファイルを再インポートしてください。特定のファイルに座標があるかどうかは、「マップ」タブのファイルテーブルで確認できます。座標のない画像には、そこにデータ行が表示されません。

### マーカーの位置がずれている

**考えられる原因**：撮影時の衛星測位が不十分だったか、撮影中にGPSのドリフトが発生したためです。**対処法**：これは撮影時の問題であり、Chlorosで事後修正できるものではありません。 高精度な作業を行う場合は、PPK/RTK GPSワークフローを使用してください。[プロジェクト設定](../project-settings/project-settings.md)の**「PPK補正を適用」**設定を参照してください。

### 地図が空白になる、またはタイルの読み込みが停止する

タイルプロバイダーはオンラインサービスです。タイルの配信が停止した場合は、マシンのネットワーク接続を確認し、プロバイダーを切り替えてみてください。極端にズームしていた場合は、**×**のリセットボタンを押して通常のズームレベルに戻し、地図がタイルを再リクエストできるようにしてください。***
