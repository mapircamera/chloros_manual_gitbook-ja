# LATTICE カメラ

LATTICE は、農業および科学分野のイメージング向けに MAPIR が開発したモジュール式のマルチスペクトルカメラシステムです。 すべての LATTICE カメラは、ソニー製 IMX265 グローバルシャッターセンサー（**

3.1 MP、3.45 µm ピクセル**）を搭載しており、**GigE Vision** デバイスとしてイーサネット経由で接続されます。

Chloros 1.2.0 は、3 つのインターフェースから LATTICE カメラをリアルタイムで制御します（検出、ライブプレビュー、撮影、および同期されたマルチカメラアレイ）：

| インターフェース    | 場所                                                          | 対応プラットフォーム                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| GUI        | Chloros サイドバーの **カメラ** タブ                         | Windows 10/11 x64                                        |
| CLI        | `chloros-cli lattice` コマンドファミリー                           | Windows 10/11 x64, Linux x86_64, Linux aarch64 (Jetson) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64, Linux x86_64, Linux aarch64 (Jetson) |

> **ハードウェアをお探しですか？**カメラモジュール、レンズ、フィルターおよびバンド、フレームおよび取り付け金具、ケーブル、PoEおよびトリガー配線については、[**LATTICEユーザーマニュアル**](https://mapir.gitbook.io/lattice-camera)に記載されています。 この章では、Chlorosからのカメラ駆動について説明します。

LATTICEのキャプチャデータは標準的な`.tif`/`.tiff`ファイルであり、Chlorosは常に生のキャプチャデータから処理を行います。 完全なコマンドについては、[CLI リファレンス](../reference/cli-reference.md) および [SDK リファレンス](../reference/sdk-reference.md)を参照してください。

## 2つのセンサー構成

| 構成 | センサー       | フィルター                                | 1台のカメラが提供するデータ                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| ベイヤーカラー | 3バンドパスフィルター                |**1回の露光で3つの較正済みバンドを取得**                 |
| **M3M**| モノクロ       | 単一の狭帯域干渉フィルター |**1つの較正済みバンド**；指標を得るには複数のM3Mカメラを組み合わせる |

M3Mカメラは単一のフィルターを介したモノクロカメラであるため、各バンドごとに個別の露光が行われます。一方、M3Cカメラは1回のセンサー露光で3つのバンドすべてをカバーします。

## モデル文字列と命名規則

すべてのカメラは、GenICam `DeviceUserID` 形式のモデル文字列として自身の識別情報を保存しています：

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

Chlorosは、`LATT-`というプレフィックスを付けて表示されます（例：`LATT-M3M-L87-F450`）。 この同じ「`LATT-…`」という文字列は、すべてのエクスポートの EXIF タグに書き込まれ、処理済みのプロジェクトではカメラの出力フォルダ名として使用されます。

| コンポーネント | 値                                                   | 意味                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| センサー    | `M3C` / `M3M`                                            | ベイヤーカラー / モノクロ                                                                          |
| レンズ      | `L41` / `L87`                                            | 数値は**水平画角（度）**を表します： L41 = 狭角 (41°)、L87 = 広角 (87°)    |
| フィルター    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) または `F<nm>` (M3M) | [フィルターとスペクトルバンド](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) を参照 |

モデル文字列は下流のすべての処理を制御します。Chloros は、`DeviceUserID` および `DeviceSerialNumber` からセンサープロファイル、バンドレイアウト、および工場出荷時のキャリブレーションを特定します。 カメラごとに設定する必要はありません — [カメラの接続](connecting.md)を参照してください。

## フィルターとバンド

バンド中心、FWHM エッジ、および 23 種類の SKU からなる M3M カタログ全体は製品仕様であるため、ハードウェアマニュアルに記載されています：[**フィルターとスペクトルバンド**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands)。

ソフトウェア側で重要な点：モデル文字列内のフィルターコードによって、Chlorosが生成できる製品が決まります。 RGBフィルター搭載カメラ（`FRGB`）は、デベイヤー処理済みおよびプレビュー製品のみを出力します。広帯域センサーでは、バンドごとの放射輝度や反射率は意味をなさないため、 そのため、Chlorosはこれらをスキップし、その旨を明示します。その他のすべてのフィルターでは、放射輝度 → 反射率 → インデックスの完全なチェーンが得られます。

## 放射計校正の概要

すべてのLATTICEカメラは、NISTにトレーサブルな測定チェーンに基づいて工場で個別に較正され、カメラごとの証明書が同梱されています。 その内容、測定方法、および引用可能な精度については、ハードウェアマニュアルの [**工場出荷時放射測定校正**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration) に記載されています。

ソフトウェア面では、カメラが接続された際にChlorosが適切な校正を特定し、適用された係数をすべてのエクスポートデータに固定することが重要です — [カメラの接続](connecting.md)を参照してください。
