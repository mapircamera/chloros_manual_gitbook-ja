# カメラ設定

**「カメラ」**タブは、Chloros

におけるLATTICEカメラ用のライブコントロール画面です。ここには、接続されたすべてのカメラをライブタイルとして表示するメインフィードエリアと、3つのページ（**「カメラリスト」**、**設定ペイン**（カメラごと、アレイ、またはキャプチャ設定 — 一度に1つずつ）、そして**インデックス計算機**——の3つのページ間をスライドして切り替えることができます。このページでは、カメラリスト、カメラごとの設定ペイン、およびアレイ設定ペインにあるすべてのコントロールについて説明します。キャプチャモード、エクスポート形式の選択、および「すべてキャプチャ」フローについては、関連ページ [キャプチャ設定とモード](capture.md) を参照してください。

「Chloros

」バックエンドの準備が整うと、サイドバーに「カメラ」タブが表示されます。以下のすべてのコントロールは、`127.0.0.1:5000`を介してローカルバックエンドと通信します。特に記載がない限り、変更はライブカメラに即座に反映されます。

## メインのフィード領域

カメラが接続されていない場合、フィード領域には **「カメラを接続して開始してください」**というスプラッシュ画面が表示され、2つのボタンがあります：**「カメラを接続」**（緑色、単一カメラの接続ダイアログを開きます）と**「アレイを接続」** （青色、アレイ接続ダイアログを開く）です。接続ダイアログ自体の詳細については[カメラの接続](connecting.md)に、アレイの概念（同期、階層、帯域幅）については [マルチカメラアレイ](arrays.md) に記載されています。カメラが含まれている保存済みプロジェクトを開くと、Chloros

が前回のセッションのストリームを復元している間、スプラッシュ画面には「N台の保存済みカメラを再開中…」というメッセージとスピナーが表示されます。

### トップバー

| コントロール | 機能 |
| --- | --- |
| **表示モードの切り替え**|**グリッド表示**（すべてのタイルがセルとして表示）と**リスト表示**（上部に全幅のアレイ、その下にアクティブなカメラが1台）を切り替えます。ツールチップ：「グリッド表示に切り替える」 / 「リスト表示に切り替える」。 |
| **グリッドロック**（南京錠） | デフォルトは**ロック** — タイルが固定されます。 ロックを解除すると、タイルを任意のスロットへドラッグして並べ替え可能（隙間が維持されます）。新しいカメラが接続されるたびに、グリッドは自動的に再ロックされます。ツールチップ：「グリッドのロックを解除（タイルのドラッグを有効化）」／「グリッドをロック（タイルを固定）」。 |
| **フィードズーム** スライダー | タイルサイズ。60 px からコンテナの全幅まで設定可能。セルは 4:3 のアスペクト比を維持します。セル幅が 200 px 未満の場合、タイルをすっきり見せるために名前と fps のオーバーレイは非表示になります。 |

### フィードタイル

各カメラは合成されたライブタイルをレンダリングします。カメラはさらに、3つのグレースケール**チャンネルごとの分割**タイルを表示することも可能です（[チャンネル分割](#display-overlays-drawn-over-the-live-feed)を参照）。また、アレイは結合されたタイルをレンダリングします。 アクティブなタイルには、カメラ（またはアレイ）の色で選択リングが表示されます。

タイルにカーソルを合わせると、**X** 形の閉じるボタンが表示されます：

* **合成**タイルのチャンネル分割表示が残っている状態でそのタイルを閉じても、合成タイルだけが非表示になります。
* **スタンドアロンカメラの最後に表示されているタイル**を閉じると、そのカメラの接続が切断されます。
* **アレイに統合されたスプリットタイル**は、カメラの接続を**切断することはありません**。単に非表示になるだけです。

グリッドのロックを解除した状態で、任意のタイルを任意のスロットにドラッグできます。レイアウトはプロジェクトとともに保存されます。

## サイドバー — カメラリスト

<!-- SCREENSHOT-NEEDED: sidebar camera list pane showing a standalone camera row and an ARRAY group with indented member rows, the DAQ on/off pill visible on the array row, plus the Connect Camera / Connect Array / Capture All buttons at the top. -->

最初のサイドバーページには、接続されているすべてのカメラとアレイが一覧表示されます：

* **カメラを接続**（緑） /**アレイを接続**（青、「検出中...」と表示されます...」と表示されます）。接続ダイアログが開いている間は、どちらも無効になります。
* **すべてをキャプチャ**（赤） — [キャプチャ設定]で選択されたエクスポート形式で、リストされているすべてのカメラをキャプチャします。プロジェクトが開いている必要があります。詳細は[キャプチャ設定とモード](capture.md) に詳細が記載されています。
* **キャプチャ設定の歯車アイコン**（「すべてキャプチャ」の隣） — [キャプチャ設定ペイン](capture.md#the-capture-settings-pane) を開きます。プロジェクトがない場合やキャプチャ中は無効になります。

### カメラ行

各カメラ行には、色分けされた枠（カメラのカスタムカラー）、「CAM」というラベル — 配列メンバーには青色の **M**（マスター）または緑色の**S**（スレーブ）という役割文字がアレイメンバーに付与されます）と、表示名が表示されます。デフォルト名は `LATTICE-MODEL (serial)` です。カメラごとの設定ペインから名前を変更できます。行のボタン：

| ボタン | 効果 |
| --- | --- |
| **目**| 表示の切り替え。非表示のカメラはグリッドから外れ、**「すべてキャプチャ」の対象から除外**されます。 |
| **歯車** | カメラごとの設定ペインを開きます（次のセクション）。 |
| **一時停止 / 再生**| ライブプレビューを**表示側のみ**で停止します — バックエンドでのキャプチャは継続されます。 一時停止中のカメラはキャプチャできません。 |
| **X** | 切断。UIは即座に更新されます（理想的な場合）；バックエンドでの切断処理が完了するまでには10～30秒かかる場合があります。 |

### アレイの行

アレイの行には、アレイの色で「ARRAY」バッジ、アレイ名（アレイ設定で変更可能）、および **DAQ · オン/オフ**ピルが表示されます。アレイレベルの光センサーが設定されている場合、またはメンバーのいずれかにカメラごとのセンサーが設定されている場合、**オン**になります。ツールチップには、どのセンサーがどのカメラに信号を送っているかが正確に表示されます。メンバーカメラは、その下にインデントされて個別の行として一覧表示されます。 アレイ行のボタン：**目**（すべての構成カメラを一括で非表示／表示）、**歯車**（アレイ設定ペイン）、**X**（アレイ全体の接続を切断）。

アレイ行およびアレイ設定ペインで使用される光センサー（DLS）のステータスには、**オフ**、**待機中**（スペクトル未受信）、**アクティブ**（過去3秒以内にスペクトルを受信）、および**古くなった** — 3秒間新しいスペクトルを受信していないが、最後の測定値は*引き続き使用中*（キャプチャパス上ではDAQ測定値の有効期限は切れない）。

サイドバー上で、単体のカメラやアレイグループ全体を互いにドラッグして重ね合わせることで、リストの順序を変更できます。アレイの構成要素は個別にドラッグすることはできません。

**ヘッダー**：カメラの**カラー見本**（クリックするとネイティブのカラーピッカーが開き、サイドバーの枠線やタイルの選択リングの色を設定できます）、**名前**と鉛筆アイコンの**名前変更**ボタン（空の名前で保存すると、デフォルトの「`MODEL (serial)`」に戻ります）、および閉じるための**×**。

### ライブヒストグラム

ペインの上部には、JPEG

のプレビューから約8 Hzで計算されるライブ輝度ヒストグラムが表示されます。平均値は、カメラ自身のAE測光に合わせるため、ベイヤー加重（(R+2G+B)/4）が適用されています。

* **Orange

の破線**= AEターゲット。**水平方向にドラッグしてターゲットを変更** — ドラッグを離すとコマンドが1つ送信され、ドラッグ中はAEターゲットモードが「マニュアル」に切り替わります。
* **Green

の実線** = 実際の平均輝度（現在AEが算出している値）。
* **RGB

ボタン**（右上）：カメラのフィルターによって色分けされたバンドごとのオーバーレイヒストグラムを切り替えます（例：FRGNの場合：グレーNIR

、緑、赤）。モノクロ（M3M）カメラでは、ボタンの表示は「MONO」となり、無効化されます — モノクロでは常に単一のバンドのルマヒストグラムのみが表示されます。
* X軸のラベルは、現在のピクセルフォーマットのセンサービット深度に従います：0..255、0..1023、0..4095、または0..65535。

### 露出とゲイン

ここでの数値入力はすべて、長押しで値が変化するスピナーを使用します：タップ = ±1、1.5 秒以上長押し = ±10、3 秒以上長押し = ±100。指を離すと、その値がカメラに送信されます。

| --- | --- | --- | --- | --- |
| **露光時間 (us)**| カメラのライブ映像の最小/最大値 | 自動 | すべて | マイクロ秒単位の露光時間。**自動/手動**の切り替えが可能。自動 = カメラ側での連続自動露光。 |
| **ゲイン (dB)**| カメラのライブ最小/最大値（例：最大 48 dB） | 手動（オフ） | すべて | 独自の**自動/手動** 切り替え機能付きアナログ/デジタルゲイン。 |
| **AE 目標輝度**| 0–255 | 80、モード**自動**| すべて（AE または自動ゲインがオンの時に編集可能） | AE が目指す輝度。**自動**（デフォルト）では、ヒストグラムに基づくバックエンドコントローラがターゲットを自動的に選択し、露光をセンサーの最大値の 60～75 % に維持します。値を入力するか、ヒストグラムのオレンジ色の線をドラッグすると、**手動**に切り替わります。 |
| **AE スムージング** | 0.5–40、ステップ 0.1 | 8.0 | すべて | AE の減衰。ツールチップ：「低い値 = AE の反応が速くなる（高fpsでパルス現象が発生する可能性あり）。高い値 = 滑らかだが反応が遅くなる。&quot; デフォルトより大幅に低い値に設定すると、高フレームレート時にAEがパルス状に反応し、ストリーミングが不安定になる可能性があります。8.0が安定したデフォルト値です。 |

### スマートヴィネット

* **補正を有効にする**チェックボックス — カメラごとのヴィネット推定値を放射測定チェーンに適用します（ライブ表示**および** エクスポート時）。
* **現在のビューからキャリブレーション**— まずアレイを均一なターゲット（フラットパネル、壁、または空）に向けます。 各カメラが個別にフラット化され、ステータスに「n/N 台 · −x.x %」というフラット化の向上率が報告されます。**クリア**を選択すると推定値が削除されます。
* [ライブプレビュー](#live-preview)内のカメラごとの**ヴィネット** スライダーを使用して、カメラごとに微調整を行います。

### ライブプレビュー *(結合時のみ)** **インデックス**：チェックボックスと歯車アイコンを有効化 —**すべての**構成カメラから抽出されたバンドが表示された共有の [インデックス計算機](#index-calculator-pane) が開きます。その下の式プレビュー行には、現在の式（「式が設定されていません — 計算機を開いて作成してください」）が表示され、1秒ごとに更新されます。
* **レンダリング解像度**ドロップダウン（カメラごとのプリセットと同じ、デフォルトは720p）：ライブビューストリームの高さ**および** 保存される合成画像のエクスポートサイズ。ペイン内の注記：「プレビュー + 保存される合成画像のサイズ。カメラごとの画像は常にフル解像度でエクスポートされます。」

### レイヤーの表示 *（合成時のみ）** **有効にする** チェックボックス（デフォルトはオフ — マスターカメラの映像がそのまま表示されます。オン = レイヤー合成）。
* **前景**/**背景**ドロップダウン：各メンバーカメラ（名前別）または**インデックス**。前景が「インデックス」の場合、LUTの最小/最大範囲外のピクセルには背景レイヤーが表示されます。

### 分割表示 *（結合時のみ）*

**「メンバーカメラを表示」**—**「メンバーカメラの分割／非表示」**ボタン。これをクリックすると、各メンバーカメラのライブ映像が、合成画像の横に個別のグリッドタイルとして追加されます。タイルはアレイの既存のフレームバッファを読み取ります（追加のカメラ接続は不要）。グリッド表示のみ。プロジェクトとともにアレイごとに保存されます。

### 機能

5秒ごとに更新される読み取り専用パネル：

* **階層ラベル**：「同時キャプチャ」（緑）・「同時キャプチャ（FTD-時差エミット）」（緑） · 「時差キャプチャ（100 ms ドリフト）」（アンバー） · 「構成が大きすぎます」（赤）。
* **フレームの健全性**：「x.xx % が未完了」 — 1 % 未満は緑、5 % 未満はアンバー、5 % 以上は赤。
* **リンクライン**：「NIC {mbps} Mbps - 持続 {MB/s} MB/s」。

その他の共通する動作：

* **統合表示と個別表示** の選択はアレイ接続時に決定されます：統合 = 1つの整列された複合タイル （メンバーのフィードは「スプリットビュー」経由のみ）；分離 = 各メンバーが独自の同期されたタイルをレンダリングします。カメラが単独のフィードとアレイタイルの両方を表示することはありません。
* **自動再接続**：保存されたプロジェクトを開くと、そのカメラとアレイが復元され、ストリームが再開される前に、保存されたすべての設定がバックエンドに再適用されます。
* **キャプチャ・ゲーティング**：非表示または一時停止中のカメラは「すべてキャプチャ」の対象から除外されます。アレイが完全にブロックされるのは、すべてのメンバーが非表示または一時停止状態の場合のみです。[キャプチャ設定とモード](capture.md)を参照してください。

## 設定の保持方法

カメラタブの状態は、ブラウザ内ではなく**プロジェクトとともに**保存されます：

* 反応型の変更が行われるたびに、カメラおよび配列の状態がプロジェクトの `cameras.json` にスナップショットとして保存されます（500 ms のデバウンス処理後）。これには、カメラ名と色、露出/ゲイン/AE 設定、ピクセルフォーマット/解像度/ビニング、トリガーレート、プレビュー設定（レンダリング解像度、ノイズ除去、 シャープネス、ヴィネット、カラープロファイル、彩度／コントラスト）、向き、オーバーレイ、チャンネル分割、インデックス構成、予測AE設定、AE ROI、 配列名、表示モード、配列キャプチャ設定（ROI クロップ位置を含む）、およびグリッドブロック（フィードズーム、表示モード、グリッドロック、手動タイル順序、非表示カメラ、閉じたタイル、アクティブなカメラ）。
* 光センサーのバインディングは、プロジェクトの `sensors.json` に保存されます。
* プロジェクトを再開すると、ハードウェアが再接続され、これらすべての設定が再適用されます。
* **プロジェクトが開かれていない場合 = セッション限定**：プロジェクトがない場合、Chlorosを終了すると何も保持されません。
* プロジェクトの有無にかかわらずセッション限定：一時停止状態、スポットメーターのサンプル、カメラごとの「キャリブレーションターゲット」チェックボックス（常にオフで起動）、およびアレイアライメントプロファイル（設計上、セッションごとに再計算されます）。
* 1つの例外：**キャプチャ設定**のエクスポート選択項目およびキャプチャモードは、`cameras.json` ではなく、プロジェクトごとにローカルアプリストレージに保持されます — [キャプチャ設定とモード](capture.md)を参照してください。</array></camera></serial>
