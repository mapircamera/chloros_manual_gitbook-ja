# カメラ設定

**「カメラ」**タブは、Chlorosの LATTICE カメラ用ライブコントロール画面です。ここには、接続されたすべてのカメラをライブタイルとして表示するメインフィードエリアと、3つのページ（**カメラリスト**、**設定ペイン**（カメラごとの設定、アレイ設定、またはキャプチャ設定 — 一度に1つずつ）、そして**インデックス計算機**です。このページでは、カメラリスト、カメラごとの設定ペイン、およびアレイ設定ペインにあるすべてのコントロールについて解説しています。キャプチャモード、 エクスポート形式の選択、および「Capture All」フローについては、関連ページ [キャプチャ設定とモード](capture.md) を参照してください。

「カメラ」タブは、Chlorosバックエンドの準備が整うとサイドバーに表示されます。以下のすべてのコントロールは、`127.0.0.1:5000`を介してローカルバックエンドと通信します。特に記載がない限り、変更はカメラのライブ映像に即座に反映されます。

## このページで使用されるカメラの種類

コントロールは、選択されているカメラの種類に応じて表示または非表示になります。このマニュアルでは、以下の用語を統一して使用しています：

| 用語 | 意味 | フィルターチャンネル |
| --- | --- | --- |
| **RGBカメラ** | FRGBフィルター搭載のLATTICE M3C（モデル名に`-FRGB`を含む） | Red / Green / Blue |
| **ベイヤー式マルチスペクトル** | FRGN、FOCN、またはFNGBを搭載したLATTICE M3C | FRGN: Red / Green / NIR · FOCN: Orange / Cyan / NIR · FNGB: NIR / Green / Blue |
| **モノクロ (M3M)** | LATTICE M3M — 1つの狭帯域フィルター、1つの校正済みバンド | 単一バンド |
| **アレイ構成要素** | 同期化されたアレイの一部として接続されたカメラ（統合表示または個別表示） | 各フィルターごと |

RGBカメラには測光処理（ホワイトバランス、カラープロファイル、ガンマ）が適用されます。マルチスペクトルおよびモノカメラには放射測定処理が適用され、測光制御はスキップされます。アレイ構成要素は、ストリームレベルの設定（ピクセルフォーマット、解像度、 ビニング、トリガー、フレームレート）をアレイに委譲します。これらの行は、カメラごとのペインでは読み取り専用となり、代わりにアレイ設定ペインに移動します。

### トップバー

| コントロール | 機能 |
| --- | --- |
| **表示モードの切り替え**|**グリッド表示**（すべてのタイルがセルとして表示される）と**リスト表示**（全幅の行：各統合アレイが1つの複合行として表示され、**個別の**アレイの各メンバーは独自のフィードとキャリブレーションターゲットテーブルを持つ独自の行として表示され、その下に1台のスタンドアロンカメラ（アクティブなカメラ）が表示される）を切り替えます。 ツールチップ：「グリッド表示に切り替える」／「リスト表示に切り替える」。 |
| **グリッドロック**（南京錠） | デフォルトで**ロック**状態 — タイルが所定の位置に固定されます。ロックを解除すると、タイルを任意のスロットへドラッグして並べ替えられます（隙間が維持されます）。 新しいカメラが接続されるたびに、グリッドは自動的に再ロックされます。ツールチップ：「グリッドのロックを解除（タイルのドラッグを有効にする）」／「グリッドをロック（タイルを固定する）」。 |
| **フィードズーム** スライダー | タイルサイズ。60 px からコンテナの全幅まで。セルは 4:3 のアスペクト比を維持します。 セル幅が 200 px 未満の場合、タイルをすっきり見せるために名前と fps のオーバーレイは非表示になります。 |

### フィードタイル

各カメラは合成されたライブタイルをレンダリングします。また、カメラは 3 つのグレースケール **チャンネルごとの分割** タイルを追加で表示できます（[チャンネル分割](#display-overlays-drawn-over-the-live-feed）を表示でき、アレイは結合されたタイルをレンダリングします。アクティブなタイルには、カメラ（またはアレイ）の色で選択リングが表示されます。

タイルにカーソルを合わせると、**X**の閉じるボタンが表示されます：

* **合成**タイルを閉じても、そのチャンネル分割タイルが残っている場合は、合成タイルのみが非表示になります。
* **単体カメラの最後に表示されているタイル**を閉じると、そのカメラの接続が切断されます。
* **アレイ構成要素の分割タイル**は、カメラの接続を**切断することはありません**。単に非表示にするだけです。

グリッドのロックを解除した状態で、任意のタイルを任意のスロットにドラッグできます。レイアウトはプロジェクトとともに保存されます。

## サイドバー — カメラ一覧

<!-- SCREENSHOT-NEEDED: sidebar camera list pane showing a standalone camera row and an ARRAY group with indented member rows, the DAQ on/off pill visible on the array row, plus the Connect Camera / Connect Array / Capture All buttons at the top. -->

最初のサイドバーページには、接続されているすべてのカメラとアレイが一覧表示されます：

* **カメラの接続**（緑） /**アレイの接続**（青、スキャン中は「検出中...」と表示されます）。接続ダイアログが開いている間は、どちらも無効になります。
* **すべてをキャプチャ**（赤） — 「キャプチャ設定」で選択されたエクスポート形式で、リストされているすべてのカメラをキャプチャします。プロジェクトが開いている必要があります。 詳細は [キャプチャ設定とモード](capture.md) に記載されています。
* **キャプチャ設定の歯車アイコン**（「すべてキャプチャ」の隣） — [キャプチャ設定ペイン](capture.md#the-capture-settings-pane) を開きます。プロジェクトがない場合やキャプチャ実行中は無効になります。

### カメラ行

各カメラ行には、色分けされた枠線（カメラのカスタムカラー）、「CAM」ラベル — アレイメンバーには青色の **M**（マスター）または緑色の**S**（スレーブ）の役割文字が付いた「CAM」ラベル — および表示名が表示されます。デフォルト名は `LATTICE-MODEL (serial)` です。カメラごとの設定ペインから名前を変更できます。行のボタン：

| ボタン | 効果 |
| --- | --- |
| **目**| 表示/非表示を切り替えます。非表示のカメラはグリッドから除外され、**「すべてキャプチャ」の対象外**となります。 |
| **歯車** | カメラごとの設定ペインを開きます（次のセクション）。 |
| **一時停止 / 再生**| ライブプレビューを**表示側のみ**で一時停止します — バックエンドでのキャプチャは継続されます。一時停止中のカメラはキャプチャできません。 |
| **X** | 切断します。UIは即座に更新されます（理想的な場合）； バックエンド側の切断処理が完了するまで10～30秒かかる場合があります。 |

### アレイの行

アレイの行には、アレイの色で表示される「ARRAY」バッジ、アレイ名（アレイ設定で名前を変更可能）、および **DAQ · オン/オフ**ピルが表示されます。**オン** になっているのは、アレイレベルの光センサーが設定されている場合、*または* 構成カメラのいずれかにカメラごとのセンサーが設定されている場合です。 そのツールチップには、どのセンサーがどのカメラに信号を送っているかが正確に表示されます。構成カメラは、その下に独自の行としてインデントされて一覧表示されます。 アレイ行のボタン：**目**（すべての構成カメラを一括で非表示／表示）、**歯車**（アレイ設定ペイン）、**X**（アレイ全体の接続を切断）。

アレイ行およびアレイ設定ペインで使用される光センサー（DLS）のステータスには、**off**、**待機中**（スペクトル未受信）、**アクティブ**（過去3秒以内にスペクトルを受信）、および**期限切れ** — 過去3秒間に新しいスペクトルは受信されていないが、最後の測定値は*引き続き使用中* （キャプチャパス上ではDAQの測定値は期限切れにならない）。

並べ替えを行うまでは、リストにはまずアレイが表示され、次にスタンドアロンカメラが表示されます。カメラ（および各アレイのメンバー）は**カメラ順**で表示されます： M3C（ベイヤー）がM3M（モノクロ）より先に表示されます。M3Cの中では、FRGB、FRGN、FOCN、FNGBの順で表示され、 M3Mはフィルター波長順で、最も短い波長から先に表示されます。グリッドのデフォルトレイアウトも同様の順序に従います。サイドバーで単体カメラやアレイグループ全体を互いにドラッグして、リストの順序を変更できます。アレイの構成要素は個別にドラッグすることはできません。

**ヘッダー**：カメラの**カラースウォッチ**（クリックするとネイティブのカラーピッカーが開きます — サイドバーの枠線およびタイルの選択リングの色を設定します）、**名前**と鉛筆の**「名前の変更」**ボタン（空の名前で保存するとデフォルトの `MODEL (serial)` に戻ります）、および閉じるための**×**。

### ライブヒストグラム

ペインの上部には、JPEGプレビューから約8 Hzで計算されるライブ輝度ヒストグラムが表示されます。平均値は、カメラ自身のAE測光に合わせるため、ベイヤー加重（(R+2G+B)/4）が適用されています。

* **オレンジ色のOrange破線**= AEターゲット。**水平方向にドラッグしてターゲットを変更** — ドラッグを離すとコマンドが1つ送信され、ドラッグ中はAEターゲットモードが「マニュアル」に切り替わります。
* **緑色のGreen実線** = 実際の平均輝度（AEが現在生成している値）。
* **RGBボタン**（右上）：カメラのフィルターごとに色分けされたバンドごとのオーバーレイヒストグラムを切り替えます（例：FRGNの場合：グレーがNIR、緑、赤）。モノクロ（M3M）カメラでは、ボタンの表示は「MONO」となり、無効化されます。モノクロカメラでは常に単一バンドの輝度ヒストグラムが表示されます。
* X軸のラベルは、現在のピクセル形式のセンサービット深度に従います：0..255、0..1023、0..4095、または0..65535。

#### キャリブレーションターゲット表

この表は**検証用表示のみ**です（「検証専用 — キャリブレーションを変更しません」）。ヘッダーにはカメラのシリアル番号、フィルター、ターゲット番号、およびピクセル単位のマーカーサイズが表示され、パネルごとに1行ずつ構成されています：

* **パネル**、その後にバンドごとに1列ずつ、パネルの値が表示されます。ベイヤーカメラの場合は、3つのバンドが名称と波長で表示されます（例： FRGN：Red 660 nm / Green 550 nm / NIR 850 nm）；**モノクロ（M3M）カメラは単一のバンド**（例：`F750`）で表示され、NDVIの列はありません。
* **Sat** — パネルのピクセルのうち、飽和しているピクセルの割合（1 %以上でアンバー、5 %以上で赤）。
* **NDVI Meas**、**NDVI Theo**（パネルの基準反射率NDVI）、および**Δ** — ベイヤー方式のマルチスペクトルカメラのみ。「NDVI Meas」の後の小さな記号は、測定されたNDVIが何に基づいて計算されたかを示します：**ρ**（反射率 — 光センサーの測定値が利用可能）、**L**（放射度 — 光センサーの測定値なし）または**DN**（カメラの生データ）。**ρ** NDVIのみが NDVI Theo と比較可能です。L および DN の場合、Δ 列はグレーアウトされ、次のような注記が表示されます （「光センサーの測定値なし：NDVIは放射度から算出されているため、Δは校正チェックにはなりません」／「NDVIはカメラの生データから算出されているため、Δは校正チェックにはなりません」）。ρの場合、Δは0.02未満で緑、0.05未満で黄、それ以外は赤で表示されます。

### 露出とゲイン

<!-- SCREENSHOT-NEEDED: per-camera Exposure & Gain section — Exposure (us) and Gain (dB) rows with Auto/Manual toggles, AE Target Brightness, AE Smoothing slider, AE Region of Interest row with the Aim button, and (on an array camera) AE Tune Speed and Highlight Protection rows. -->

ここでの数値入力はすべて、長押しで加速するスピナーを使用します：タップ = ±1、1.5 秒以上長押し = ±10、3 秒以上長押し = ±100。指を離すと、その値がカメラに送信されます。

| 制御項目 | 範囲／選択肢 | デフォルト | 適用対象 | 機能 |
| --- | --- | --- | --- | --- |
| **露出 (us)**| カメラのライブ表示の最小/最大値 | 自動 | すべて | マイクロ秒単位の露出時間。**自動/手動**トグルがあります。自動 = カメラ側での連続自動露出。手動露出を設定しても、**ゲイン**が「自動」のままの場合は、ゲインを編集するか「手動」に設定するまで、カメラのゲイン範囲全体を自由に使用できます。 |
| **ゲイン (dB)**| カメラのリアルタイム最小/最大値（例：最大 48 dB） | 手動 （オフ） | すべて | 独自の**自動/手動**切り替えを備えたアナログ/デジタルゲイン。 |
| **AE 目標輝度**| 0–255 | 80、モード**自動**| すべて（AE または自動ゲインがオンの時に編集可能） | AE が目指す輝度。**Auto**（デフォルト）では、ヒストグラムに基づくバックエンドコントローラーが目標値を自動的に決定し、露出をセンサー最大値の60～75％に維持します。値を入力するか、ヒストグラムのオレンジ色の線をドラッグすると、**Manual**に切り替わります。 |
| **AE スムージング** | 0.5–40、0.1刻み | 8.0 | すべて | AEの減衰。ツールチップ：「低い値ほどAEの反応が速くなり（高fpsでパルス現象が発生する可能性あり）。高い値ほど滑らかだが反応が遅くなる。」デフォルトより大幅に低い値に設定すると、高フレームレート時にAEがパルス現象を起こし、ストリーミングが不安定になる可能性があります。8.0が安定したデフォルト値です。 |
| **AE 関心領域**| 有効化チェックボックス +**照準**ボタン | オフ | すべて | オンにすると、AEはフレーム全体ではなく、緑色の破線で囲まれた領域のみを計測します。**「エイム」**は、ライブフィード上でクリックして配置する機能を有効にします。クリックするとフレームの30％の位置に領域が中央配置され、クリック＆ドラッグでカスタム矩形（最小5％×5％）を描画できます。**Aim**は1回の配置後に自動的に無効化されます。この領域は、設定された回転や反転にかかわらずカメラのネイティブ座標系にマッピングされ、プロジェクトとともに保存されます。 |
| **AE 調整速度** | 0.1–5、0.1刻み | 1.0 | 配列メンバーのみ | 自動AEターゲットがシーンの明るさの変化を追跡する速度。1.0×の場合、2.5秒ごとに再チェックを行います。 |
| **ハイライト保護** | 厳格 (1 %) / 標準 (5 %) / 緩やか (15 %) | 厳格 | 設定を公開しているカメラ | AE が画像を暗くする前に、フレームのどの程度までが白くクリップされてもよいか。 |

**ベイヤー型マルチスペクトルカメラ（RGN / OCN / NGB）の光量要件：** 3つのチャンネルすべてに十分な光量がない場合、キャリブレーションは正しく機能しません — 1回のセンサー露光で3つのスペクトルすべてをカバーします。DAQ光センサーを使用して光量を測定するか、各バンドに個別の露光が行われるよう、オールモノ（M3M）モードを使用してください。撮影がこの要件に違反している場合、Chlorosがそれを検出して警告します（アンミックス・クランプ通知）。 ライブ表示では、チャンネルの分割タイルに、そのバンドのピクセルの25％以上でアンミックスがクランプされた場合、**「信頼度の低いバンドデータ · N%」**と表示されます。
{% endhint %}

{% hint style="info" %}
**自動露出による露出時間とゲインの割り当て方法（1.3.0）。** ゲインを「自動」に設定すると、Chlorosは、露光が許容される最長値（AE上限、アレイのトリガー周期、またはDAQ露光上限）に達するまで、ゲインを0 dBに維持します。その時点で初めてゲインが上昇します。アレイでは、トリガーレートが最優先されます。自動露光は、そのレートによって定められた期間を埋めた後、その後ゲインを上げます。そのため、暗くなるシーンでも自動トリガーレートは低下しなくなりました（バージョン1.2.0では低下していました）。アレイの構成要素で、トリガー周期よりも長い**手動**露光が行われると、アレイのトリガーレートはその露光時間に合わせるために遅くなります； 自動トリガーレートは、その速度低下を引き起こした各メンバーがすべて自動露出に戻った時点で、元の状態に戻ります。**露出**と**AE目標輝度**の両方が「自動」に設定され、DAQ光センサーが測定値を提供している場合、自動露出が安定した後、測定された光量が約±25％の範囲内に留まっている限り、各カメラの露出は維持されます。 より大きな光量の持続的な変化、設定の再起動（例えばROIの変更）、またはユーザーによる露出変更があると、自動露出が再起動します。
{% endhint %}

{% hint style="info" %}
**自動露出の動作について (1.3.0)。**

* 手動露出の場合、ゲインを変更するまでゲインは「自動」のままになります。
* 小さなハイライトはシーンを暗くしません。フレームの 1 % までのスペキュラーは無視され、既知のキャリブレーションターゲットのパネル内では、パネル面積の 0.5 % までが対象外となります。
* DAQ 露出上限は、キャリブレーションターゲットが視野内にある間のみ適用されます。パネルが視野にない場合、カメラはシーンに合わせて露出を調整します。
* 露出は一定の光量下では安定し、大きな変化があっても数秒以内に落ち着きます。クリップが発生しても露出が恒久的に上限に達することはなくなり、ROIを変更しても露出が再調整されます。
* 輝度ターゲットはカメラの範囲内にとどまるため、光が戻ってもフレームがフレアを起こすことはありません。
* 明るい日差しの下で自動露出が反応しなくなったカメラは、光センサー（接続されていない場合はカメラ自身のフレーム）によって読み取られた現在の光量レベルに維持され、 、光量が変化するとその設定を解除します。光センサーが暗くなったり覆われたりしても、この動作は妨げられません。
{% endhint %}

### スポットメーター

* **クリックしてサンプリング**チェックボックス：ライブ映像をクリックして単一のピクセルをサンプリング（十字線が表示されてマークされます）、または領域をクリックしてドラッグし、ピクセルの平均値を算出します。**クリア**をクリックすると、サンプリングデータと十字線が消去されます。AE-ROIの**エイム**モードとは排他的です。

**DAQ駆動の露出上限および入射光固定AE。** 上記のチェックボックスの設定とは関係なく、DAQ光センサーがRGBカメラに割り当てられている場合、Chlorosは — 測定された絶対下向き放射照度から — 反射率100％の表面がクリッピングを下回る最大露出×ゲインを計算し、これを自動露出の**上限**として適用します。バージョン1.3.0以降、この上限は、キャリブレーションターゲットがそのカメラの視野内にある間（過去10秒以内にフレーム内に捉えられた場合）にのみ適用されます。 ターゲットが視野内にない場合は、そのカメラ独自のハイライト保護機能を備えた通常の自動露出が代わりに動作するため、シーンの他の部分が必要以上に暗く抑えられることはありません。シーリングが有効な間、カメラは**入射光固定**状態になります。つまり、ゲインを0 dBに設定した入射光測光による露光でオープンループ動作を行い、露光はシーンの内容ではなく、測定された光量に従います。上限値は露光時間を短縮することしかできないため、それ自体でクリッピングを引き起こすことはありません。 バージョン1.3.0以降、上限値はキャリブレーションパックに含まれるカメラ固有の露出定数に基づいて計算されます（パックに値が含まれていない場合のみ、フリート平均値が使用されます）。キャリブレーションターゲットが視野に入っていない場合、DAQの測定値が欠落している、古い （30秒以上経過）、または暗い場合、あるいは固定された露出でフレームの15％以上がクリップしている場合（センサーとカメラが異なる照度を検知していることを意味する）には、シーリングは自動的に無効化され、通常のシーンAEが再開されます。GUI上の切り替えスイッチはなく、RGBカメラにDAQがバインドされている場合は常にこの動作が標準となります。

#### ROI エディタ

1.3.0での新機能。ROIクロップ行とその下のマップは連動して機能します：

* **ROIオン / ROIオフ**— センサーのクロップを**即座に**オンまたはオフにします（カメラが一時的に再起動し、アレイタイルに「設定を適用中…」と表示されます）。**オフ**を選択するとセンサー全体が読み込まれ、**クロップ設定が保持**されます（各フィールドには設定値が表示されたままになります）。**オン**を選択すると、設定が再度適用されます。クロップ設定がない状態でROIをオンにすると、中央に配置された半分のサイズのクロップが適用されます（「クロップ設定がないため、中央に半分のサイズのクロップが適用されました。各フィールドで調整してください。」）。
* **選択**— マップ上にクロップを描画します：範囲をドラッグするか、対角にある2つの角をクリックします（Escキーでキャンセル）。矩形はW/H/X/Yフィールドに反映され、 上記の手順に合わせてスナップされます。**適用**を押すまでは何も適用されないため、まずフィールドの矢印を使って微調整が可能です。「選択」を押すたびに1つの矩形が作成されます。
* **マップ**にはセンサー全体に対するクロップが表示されるため、元に戻すことも可能です：カメラがセンサー全体を読み取っている間は「フルセンサー、ライブ」、 または「{時間}時点のフルフレームスナップショット。カメラはクロップ領域のみを読み取ります。」と表示されます。アレイがこれまでクロップされたデータのみをストリーミングしていた場合、マップには「まだフルフレームビューはありません：このアレイはクロップされたデータのみをストリーミングしています。」と表示され、**フルフレームを表示**ボタンが表示されます。このボタンを押すと、ROIがオフになります。クロップのラベル「`W×H @ X,Y`」は、マップ上およびライブタイル上で、ボックスの外側（ボックスの上、またはボックスが上端に接している場合は下）に表示されます。
* **適用**を実行するとフィールドが確定されます。クロップの場合は ROI がオンになり、フルフレーム（**リセット** 後の状態）の場合は ROI がオフのままとなり、以前のクロップ設定は保持されます。ROI がオフで、フィールドに以前のクロップ設定が表示されている状態では、別の変更（フォーマット、ビニング、レート）を適用しても ROI はオフのままとなります。
* **アライメント済みのアレイでは、各メンバーのクロップウィンドウはアライメントによって配置される**ため、すべてのカメラがシーンの同じ領域をフレームに収めます。アライメントを行う前にクロップされたアレイは、まずフルセンサーでアライメントが行われます（クロップが解除され、アライメントが解決され、カメラごとのウィンドウでクロップが復元されます）。
* クロップ変更後、自動露出は新しいフレーミングに合わせて再収束します。クロップが適用されている間も、メンバーの露出はトリガー期間まで継続して実行されます。
* ROIのオン/オフ状態と記憶されたクロップは、プロジェクトとともに保存されます。

## カメラごとの設定とアレイ管理設定

カメラがアレイのメンバーである場合の、各設定の配置に関するクイックリファレンス：

| アレイ管理（カメラペインでは読み取り専用） | アレイ内でもカメラごとの設定 |
| --- | --- |
| ピクセル形式、解像度、ビニング | 自動露出（露出、ゲイン、ターゲット、スムージング、ROI） |

その他の共通動作：

* **統合表示と個別表示**はアレイ接続時に選択されます：統合 = 1つの位置合わせされた合成タイル（メンバーのフィードは「分割表示」経由でのみ表示）；個別 = 各メンバーが独自の同期されたタイルをレンダリングします。カメラが単独のフィードとアレイタイルの両方を表示することはありません。

## 設定の保持方法

カメラタブの状態は、ブラウザ内ではなく**プロジェクトとともに**保存されます：

* 反応型の変更が行われるたびに、カメラおよびアレイの状態がプロジェクトの `cameras.json` にスナップショットとして保存されます（500 ms のデバウンスあり）。これには、カメラ名と色、露出／ゲイン／AE設定、ピクセルフォーマット／解像度／ビニング、トリガーレート、プレビュー設定（レンダリング解像度、ノイズ除去、シャープネス、ヴィネット、カラープロファイル、ハイライト、彩度／コントラスト）、向き、オーバーレイ、チャンネル分割、インデックス構成、予測AE設定、AE ROI、 アレイ名、表示モード、アレイのキャプチャ設定（ROIクロップ、ROIの有効/無効、および無効時の記憶されたクロップを含む）、アレイのワイヤ・バジェット、およびグリッドブロック（フィードズーム、ビューモード、グリッドロック、手動タイル順序、非表示カメラ、閉じたタイル、アクティブなカメラ）。
* 光センサーのバインディングは、プロジェクトの `sensors.json` に保存されます。
* プロジェクトを再開すると、ハードウェアが再接続され、これらすべての設定が再適用されます。
* **プロジェクトが開かれていない場合 = セッション限定**：プロジェクトがない場合、Chloros を終了すると何も保持されません。
* プロジェクトの有無にかかわらずセッション限定：一時停止状態、スポットメーターのサンプル、カメラごとの「キャリブレーションターゲット」チェックボックス（常にオフで開く）、およびアレイ位置合わせプロファイル（設計上、セッションごとに再計算されます）。
* 1つの例外：**キャプチャ設定**のエクスポート選択項目およびキャプチャモードは、`cameras.json` ではなく、プロジェクトごとにローカルアプリストレージに保持されます — [キャプチャ設定とモード](capture.md)を参照してください。</array></camera></serial>
