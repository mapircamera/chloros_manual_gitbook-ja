# ターゲット画像の選択

どの画像にキャリブレーションターゲットが含まれているかを指定することで、Chlorosはターゲットを正確に検索できるようになります。「Target」列で少なくとも1つの画像にチェックを入れると、Chlorosは**チェックされた画像のみ**をスキャンします。したがって、ターゲットを指定することは、処理を高速化すると同時に、調査画像をターゲットと誤認するのを防ぐ方法でもあります。

## なぜターゲット画像をマークするのか？

### マークによってスキャンが制御される

特定の画像の「ターゲット」列にチェックを入れると：

* Chlorosは、チェックされた画像のみを対象にターゲットをスキャンします
* ターゲット検出がはるかに高速に完了します
* 測量画像による誤ったターゲット検出が発生しません

**画像が1枚も**チェックされていない場合、Chlorosはプロジェクト内のすべての画像をスキャンするモードに切り替わります：

* 各画像に対してターゲット検出アルゴリズムが実行されます
* 数百枚、あるいは数千枚もの画像が不必要にチェックされます
* 特に大規模なデータセットの場合、処理にかなり長い時間がかかります

{% hint style="success" %}
**処理速度の向上**：500枚の画像からなるデータセットで2～3枚のターゲット画像をマークするだけで、ターゲット検出時間を30分以上から1分未満に短縮できます。
{% endhint %}

***

## ターゲット画像のマーク方法

### ステップ1：ターゲット画像の特定

ファイルブラウザでインポートされた画像を確認し、どの画像にキャリブレーションターゲットが含まれているかを特定します。

**一般的なシナリオ：*** **撮影前のターゲット**：セッション開始前に撮影されたもの
* **撮影後のターゲット**：セッション終了後に撮影されたもの
* **現場のターゲット**：撮影エリア内に配置されたターゲット
* **複数のターゲット**：1セッションあたり2～3枚のターゲット画像（推奨）

### ステップ 2: 「ターゲット」列の確認 <img src="../.gitbook/assets/image (33).png" alt="" data-size="original">

キャリブレーションターゲットを含む各画像について：

1. ファイルブラウザのテーブルでその画像を探します
2. **「ターゲット」**列（右端の列）を見つけます
3. その画像の「ターゲット」列にあるチェックボックスをクリックします
4. ターゲットを含むすべての画像について、この手順を繰り返します

### ステップ3：選択内容の確認

処理を行う前に、以下の点を確認してください：

* [ ] キャリブレーションターゲットを含むすべての画像にチェックが入っている
* [ ] ターゲット以外の画像が誤ってチェックされていない
* [ ] チェックされた画像内でターゲットがはっきりと確認できる

## LATTICE：DAQが記録中の場合、ターゲットは任意です

LATTICEマルチスペクトルカメラの場合、フレーム内のキャリブレーションターゲットは、**2つの**反射率基準のうちの**1つ**となります：

* **フレーム内ターゲット**：マークされたターゲット画像がChlorosの品質（QA）ゲートを通過した場合、そのターゲットは周囲の画像に対する**絶対反射率基準**となります。
* **DAQダウンウェルリング**：ターゲットが存在しない場合（またはQAに失敗した場合）、Chlorosは代わりにDAQの光センサーによるダウンウェルリング放射照度から反射率を算出します（ρ = π·L/E）。 `.daq` または DAQ-M `.csv` の記録がキャプチャ範囲をカバーしている場合、**ターゲット画像を一切使用せずに**、校正済みの反射率を取得できます。

この自動動作がデフォルト設定です。 CLI / SDK では、これは `--reflectance-source auto` に対応します。また、`target`（厳密 — DAQ による置換なし）または `daq`（DAQ を優先）を強制することもできます。 [CLI リファレンス](../reference/cli-reference.md#per-product-export-toggles-lattice-multispectral)を参照してください。

**LATTICE ターゲット形状**：Survey3 で使用される従来のパネル検出に加え、LATTICE 処理では、プロジェクトごとに設定可能な**ArUco マーキング付きターゲット**、**固定 ROI ターゲット**、および**ストリップターゲット**をサポートしています。 ユニットごとの**測定済み**ターゲット反射率スキャンは、シリアル番号（CLI：`--target-reflectance-dir`、ターゲットユニットごとに1つの`<serial>.csv`）で提供可能であり、フォールバックとして公称T3/T4Pスペクトルが使用されます。

{% hint style="info" %}
**F988モジュール**：F988の反射率は、現場の反射率パネルを使用して校正されます。このバンドはDAQ光センサーの校正範囲外にあるため、Chlorosは最新のパネルキャプチャを適用し、パネル観測の間はその値を保持します。 F988モジュールがDAQのみで処理される場合、ChlorosはそのバンドのDAQベースの反射率を拒否します（スキップ理由：`dls-uncalibrated-band-988`）。パネルによるワークフローがサポートされている方法です。
{% endhint %}

## ターゲット画像のベストプラクティス

### ターゲット画像の撮影ガイドライン

**タイミング：**

* 撮影セッションの直前に、およびセッション全体を通じてターゲット画像を撮影してください
* DAQの光センサーと同じ照明条件下で撮影してください
* 最良の結果を得るためには、ターゲット画像をできるだけ頻繁に撮影することが理想的です。そうでない場合は、光センサーのデータを使用して、時間の経過に伴うキャリブレーションの調整が行われます。

**カメラの位置：**

* ターゲットが中央に位置し、画像中央の約 40～60% を占めるように、カメラをターゲットの上方に保持してください。
* カメラをターゲット表面に対して平行、または天頂（ナディール）方向に向ける

**照明：**

* DAQ光センサーと同じ周囲照明環境
* ターゲット表面に影が落ちないようにする
* 身体、車両、植物などで光源を遮らない
* 曇天時が最も安定した結果が得られます

**ターゲットの状態：**

* ターゲットパネルを清潔で乾燥した状態に保ってください。
* ターゲットのすべてのパネル（例：T4の場合は4枚すべて）がはっきりと見え、遮られることがないようにしてください。
* 可能であれば、ターゲットを光源に対して垂直、または真下（ナディール）に配置してください。

### ターゲット画像の枚数：

**最低:**1回のセッションにつき1枚のターゲット画像。**推奨:** 1回のセッションにつき3～5枚のターゲット画像。**ベストプラクティスのスケジュール:**

* 光センサーの記録開始直後に3～5枚の画像を撮影する
* 最良の結果を得るために、撮影の合間にカメラの向きを回転させる
* オプション：照明条件が絶えず変化する場合は、セッションの途中で定期的に撮影する

## 複数のカメラの使用

### デュアルカメラ構成

2台のMAPIRカメラを同時に使用する場合（例：Survey3W RGN + Survey3N OCN）：

1. **両方のカメラ**で同時にターゲット画像を撮影する
2. 両方のカメラで**同じ物理ターゲット**を使用する
3. ファイルブラウザで**両方のカメラタイプ**のターゲット画像にマークを付ける
4. Chlorosは、各カメラのキャリブレーションに適切なターゲットを使用します

### 「カメラモデル」列

**「カメラモデル」**列は、どの画像がどのカメラから取得されたかを特定するのに役立ちます：

* Survey3W\_RGN
* Survey3N\_OCN
* LATT-M3M-L41-F550
* LATT-M3C-L87-FRGN
* など

この列を使用して、プロジェクト内の各カメラタイプに対してターゲットがマークされていることを確認してください。

## ターゲット検出設定

### 検出感度の調整

Chlorosがターゲットを正しく検出していない場合は、[プロジェクト設定](adjusting-project-settings.md)で以下の設定を調整してください：

**最小キャリブレーションサンプル領域 (px)：*** **デフォルト**: 25 ピクセル
* **増加**: 小さなアーティファクトで誤検出が発生する場合
* **減少**: ターゲットが検出されない場合**最小ターゲットクラスタリング (0-100):*** **デフォルト**: 60
* **値を大きくする**: ターゲットが複数の検出に分割されてしまう場合
* **値小さくする**: 色のばらつきがあるターゲットが完全に検出されない場合

{% hint style="info" %}
**『CLI』のヒント**：`chloros-cli process`は同じノブ（`--min-target-size`、 `--target-clustering`）を受け付け、その `--target`/`--targets` フラグは、入力フォルダ全体を「ターゲットパネルのみ」としてマークします。 [CLI リファレンス](../reference/cli-reference.md)を参照してください。
{% endhint %}

## ターゲット画像に関する一般的な問題

### 問題：ターゲットが検出されない

**考えられる原因：**

* ファイルブラウザでターゲット画像にマークが付けられていない
* フレーム内のターゲットが小さすぎる（画像の 30% 未満）
* 照明条件が悪い（影、まぶしさ）
* ターゲット検出の設定が厳しすぎる

**解決策：**

1. 対象の画像について、「ターゲット」列にチェックが入っていることを確認する
2. プレビューでターゲット画像の品質を確認する
3. 品質が不十分な場合は、ターゲットを再撮影する
4. 必要に応じて、ターゲット検出設定を調整する

### 問題：誤ったターゲット検出

**考えられる原因：**

* 白い建物、車両、または地表の被覆がターゲットと誤認されている
* 植生内の明るい部分
* 検出感度が低すぎる

**解決策：**

1. 実際のターゲット画像のみにマークを付ける — チェックされた画像のみがスキャン対象となる
2. 最小キャリブレーションサンプル領域を拡大する
3. 最小ターゲットクラスタリング値を引き上げる
4. ターゲット画像にはターゲットのみが写っていることを確認する（背景の雑音を最小限に抑える）

## 検証チェックリスト

処理を開始する前に、ターゲット画像の選択を確認してください：

* [ ] セッションごとに少なくとも1枚のターゲット画像がマークされている（または、LATTICEの場合は、そのセッションを網羅する`.daq`/`.csv`の記録がある）
* [ ] すべてのターゲット画像について、ターゲット列のチェックボックスがオンになっている
* [ ] ターゲット画像は調査と同じ時間枠内で撮影されている
* [ ] クリックした際にプレビューでターゲットがはっきりと確認できる
* [ ] 各ターゲット画像にすべてのキャリブレーションパネルが表示されている
* [ ] ターゲットに影や遮蔽物がない
* [ ] デュアルカメラの場合：両方のカメラタイプでターゲットがマークされている

## ターゲットなしの処理

### LATTICE：DAQ記録を使用する場合

LATTICEの撮影中にDAQ光センサーが下向き放射照度を記録していた場合、ターゲットは必要ありません：

1. 画像データを含む `.daq`（または DAQ-M `.csv`）ファイルをインポートします
2. 「ターゲット」列のチェックを外したままにします
3. 反射率は、DAQ の下向きの基準値から自動的に計算されます
4. 放射輝度（Radiance）にはターゲットやDAQが一切不要です。これはカメラの工場出荷時の放射測定校正のみに基づいて算出されます

### 参照データなしでの処理

ターゲットやDAQを使用せずに処理を行うことも可能です：

1. 「ターゲット」列のすべてのチェックボックスをオフにします
2. プロジェクト設定で「反射率キャリブレーション／ホワイトバランス」を**無効**にします。これにより、ターゲットの検出が完全にスキップされます
3. ヴィネット補正は引き続き適用されます
4. 出力は絶対反射率に対してキャリブレーションされません（LATTICEマルチスペクトルは、デベイヤー処理済みのプレビューおよびラディアンス製品をエクスポートします）

{% hint style="warning" %}
**Survey3での科学的研究には推奨されません**：反射率キャリブレーションを行わない場合、Survey3のピクセル値は相対的な輝度のみを表しており、科学的な反射率測定値ではありません。正確で再現性のある結果を得るには、キャリブレーションターゲット（または、LATTICEの場合はDAQ光センサー）を使用してください。
{% endhint %}
